# P2 限制、负结果保留与解释边界

**本文件未读取本轮outer风险或分数，不预判正负结果。** 它记录在正式评测前已经确定的限制，以及最终报告必须保留的反例和未完成事项。具体DSS点估计、seed/fold方向、模型增量、训练趋势和最终研究裁决须引用实际完成后生成的05–11报告；没有成功训练与回放的比较只能记NA/NOT_RUN及原因。

## 数据来源、缺失与患者单位

- 当前合同为同一TCGA COAD/READ队列：512名患者、65个DSS事件。五折曾在此前研究中反复开发；本轮仍是内部开发暴露的患者级交叉验证，不是新的外部独立确认。3个seed改变初始化/部分训练选择，不创造3个队列；15个fold×seed cells也不是15个独立样本。
- 多张切片必须随同一患者留在同一fold；512个patch预算是工程采样上限，不等于完整WSI或全部肿瘤区域。按片内读取、患者等片汇总，不能把切片更多当作更多独立患者。
- canonical RNA为20,511个唯一非空符号、CNA为25,101个。原表行数20,531/25,131不能未经符号过滤/合并直接当作canonical列坐标。来源审计已逐元素确认原表→raw→canonical以及parent继承，没有canonical跨患者全局填补。
- RNA的203名患者每人缺3,015个canonical基因，其余309人完整；对应raw为203×3,024源行。该分组包含COAD144人和READ59人，不能从缺失形状直接断言平台或生物学原因。当前loader的platform字段是精确缺失模式代理，不是已验证测序平台标签。
- CNA剩余260个缺失单元格恰为全部READ130人×2列，COAD382人完整。这是已证实的队列来源相关缺失结构，不能把模型对该差异的利用自动解释成分子机制。缺失不是零表达、正常拷贝数或阴性生物学状态。
- 同符号观测合并可恢复该符号的实测值，但不保留全部源行/转录本细节；RNA/CNA的程序覆盖、bulk混合来源、肿瘤纯度及取材差异仍可能影响表征。CNA增益/缺失分开编码不等于识别程序活性，也不证明RNA与CNA同名程序具有同一机制。

上述来源事实的数值和SHA见 `01_CANONICAL_OMICS_SOURCE_AUDIT.md/json`。公开JSON只将身份数组的纯哈希元数据键改名，保留真实执行原件及投影器绑定；这不是重新跑数据实验或修改结果。

## 强锚点与控制的实际作用范围

**共同r0已经包含组学风险。** 它是原GRID-local CONCH PCA32＋Clinical6＋TITAN S32的CP风险，再加旧八程序union范围RNA512的独立Ridge Cox风险及同teacher标量校准。因而本轮增量是在该强多模态、已有RNA路径的锚点之上估计；B5若没有增量，不能推出RNA不存在独立DSS信号。

B0保留旧GRID与旧RNA成员配方，新B1–B7使用REGIONS512和Hallmark50表示。B5−B0衡量实际预测竞争力，存在输入配方差异，不能单独归因于架构。B0每fold仅一次确定性配方，不能伪装成三seed重拟合；seed31历史风险核查也不能替代历史三seed均值复现。P2训练offset对包括监督beta的整个R4管线再交叉拟合，历史own-beta训练向量不是同一个统计对象。

| 控制 | 能回答的问题 | 不能据此声称 |
|---|---|---|
| B4−B3 | 在共享真实S32等共同输入下，固定Query身份的作用 | 完整模型中全部语言知识是否必要 |
| B3_TEXTLESS_INCREMENT | 移除增量adapter显式文本Query与概念分数的作用 | 整体风险无文本；r0仍含TITAN S32 |
| B1 | 共享预训练之后，Phase-B加性读出的竞争力 | 从表征训练到预测完全没有跨模态学习 |
| B7 | 共享预训练/背景下去除Phase-B跨模态乘积 | 完全删除所有跨模态监督或所有Clinical条件关系 |
| B4_MAP_SHUFFLE | 固定Query下候选关系结构的作用 | 关系已被医学真值验证、加权列和或全部测量支持天然相同 |
| B6a | 训练辅助正对分配的患者身份作用 | 错误替换整个RNA模态，或自然部署中的错配性能 |
| B5临床容量控制 | 排除新增临床自由度的替代解释 | 自动证明残差严格统计正交或生物学因果互补 |
| B2_MATCHED/NATIVE | 同token预算下常规注意力适配竞争力 | 论文官方原生模型或真实SOTA完整复现 |

B1/B4/B5/B7及临床容量控制合法共享MAIN Phase-A权重，减少重复训练；这不等于每个读出都独立训练了一套encoder。B6a正对改变，必须独立真实训练。配对损伤/修复是可比较风险排序诊断，不是患者治疗获益或生物学因果交互。

## 基础模型与语义解释

CONCH-Z必须使用其匹配图像投影，TITAN原型/slide表示必须使用合法共享空间；raw patch特征不能直接与不匹配文本做cosine。官方接口与缓存数值一致只是技术资格，不保证所称概念在当前队列具备组织学真值。

冻结医学FM的预训练数据可能与TCGA存在重叠，当前未核清患者/slide级重叠范围。因此不能把其输出当作本轮独立外部监督或严格未见样本语义确认。没有原始WSI与独立ROI标注的组织学QA，不能把TITAN分数、slot、注意力或程序预测命名为已验证的细胞来源、肿瘤出芽或真实病理事件。

当前concept–Hallmark关系是有来源、允许关联的候选，不是患者级因果映射；unknown不是负边。Bulk RNA程序可能反映细胞组成与细胞内活性的混合，不能把程序活跃直接等同于可见形态。真实Query或真实关系若不优于控制，应保留该负结果，不能重命名latent、重新筛概念或扩大图后覆盖原结论。

## 训练预算与实现资格

固定400个inner患者epoch只证明执行了该预算，**不证明收敛、充分优化或模型失败是idea失败**。必须检查全部训练曲线、实际validation checkpoint、选中epoch、200→400趋势、Huber容忍带与hard-gap之间的关系；selected epoch=400和原始Huber唯一最小值在400是不同事实。完整曲线不进行采样、量化或插值出并未运行的验证点。

注册参数、非零训练梯度、非恒定risk design列、非零拟合系数、对最终预测的逐参数因果作用是不同层次。静态路径计数或总梯度不能冒充逐参数干预验证。现有FLOPs profile覆盖支持的矩阵算子，不覆盖全部算子；不据此声称墙钟或显存完全匹配。B2原生更大版只作为强竞争者，不能用它与matched版的容量差异替代机制证据。

无DSS Phase A、临床背景OOF、teacher训练offset和完整风险集Cox分别有独立隔离边界；同一冻结坐标系的Ridge背景不能由不同encoder latent拼接替代。背景残差化本身不保证与全部主效应统计正交。教师、PCA、临床编码和程序统计均须在当前训练分区重新拟合。

软件单元测试、已有真实profile、旧95份风险重评分、P1R、原F1两次50更新，以及新增106 Cox的DSS隔离资格必须分scope计费，不能充作480正式拟合。两个资格旁路与历史风险核查在真实执行前只能报告预锁和代码资格，不能填PASS。即使资格通过，也只支持指定输入/分区/路径的隔离性质，不构成外部效度或全模型医学解释证明。

## 评测、裁决与负结果保留

主Harrell与Uno60均按fold内部pair分子/分母汇总，再seed等权；不能跨fold比较风险尺度。Uno使用对应fit-train reverse-KM，缺乏支持时保留NA，不裁剪成有限漂亮分数或丢弃不利fold后重归一。训练头的in-sample排序、OOF teacher offset和outer评测不是可混称的统计对象。

按用户合同，本轮不计算CI、bootstrap或p值；这不消除有限事件和重复开发导致的不确定性。`0 < Δ < 0.005`仅描述为弱正向点估计；它不是显著性阈值、概率判断或泛化保证。必须同时呈现Harrell/Uno、三个seed、五折方向、最差fold/cell及修复/损伤。指标冲突时不得临时加权；“B0不实质恶化”没有可事后发明的数值margin。

运行报告`COMPLETE`只说明其收据/计数/算术资格，不自动授予机制成立。最终 `11_RESEARCH_DECISION.md/json` 需在以下研究裁决中如实选择并列事实理由：机制支持限内部开发队列；仅预测增益；仅语义pretext信号；当前实现无确认增益；或实现/预算仍不足以判断。若资格未合格，应记录具体阻断，不能当科学失败；若资格合格却没有方向支持，也不能无限调参回写这五折。

独立审计若只解码保存风险、重算线性头及评分组件，应保持该范围表述，不能写成原始H5→encoder→风险的第二次全链路独立复现。零fit历史核查会解码自有旧Torch容器，其中可能带既有PFI聚合分数；不使用这些字段且不读取原始PFI标签，与“整个blob从未解码过任何PFI相关元数据”并非同一说法。

优势是本轮保留来源、完整主效应、同输入控制、独立评分与失败谱系，可定位增量消失的环节。限制是这些保证主要解决实现与比较可信度，不能凭理论动机或可视化补足临床外部验证。P2结束后不自动启动P3架构搜索、换终点或换癌种；先交付完整真实报告、限制、负结果及明确研究裁决。


## 运行资源估计的实际偏差

最终阶段曾观察到六worker合计常驻显存使2 GiB预留线下穿约134 MiB，尚未发生OOM。当前worker均自然完成后，后续运行上限降为5；模型源码、已冻结选择、输入及优化轮数均未改变，完整单元经hash复用。见 `09_RESOURCE_ADMISSION_ADJUSTMENT.json` 与 `13_REPRODUCE.md` 的实际执行补充。不能以零更新profile的CUDA peak-allocated数值，替代多进程NVML总常驻显存实测；也不能把调度器的受控退出标记冒充或隐藏为模型训练失败。


## 预锁低容量读出的表示限制

主风险头按合同将病理8×64槽位、组学50×64程序和临床表示分别以训练侧无结局PCA压到8维，并保留2维机制特征，共26个系数。保留较大的上游表示再做PCA，不等于证明这8维在预后意义上充分；PCA按训练方差选择方向，不保证保留全部DSS排序信息。低秩2维交互也约束了能够检出的关系形式。

因此，本轮控制检验的是同一预锁压缩和低容量读出下的条件增量，不覆盖所有可能的组学表示或风险头。强r0仍单独保留旧RNA512风险，避免把删除原RNA主效应误称增量模块无效；但这不能替代对新增latent预后信息可解码性的独立验证。若结果不支持增量，不能从中推导“所有RNA条件信息均不存在”；也不得用已经看到的外折成绩挑新的PCA维度或rank替换本轮主结果。
