# Phase25-A：现有轻量视觉基线与 C4 的只读归因审计

## 结论与审计范围

**Clinical+S32+CONCH32 的高点估计不能仅用 CS 系数重优化解释；现有证据也没有确认它来自局部选区的独特作用。C4 的非线性分支确实改变风险，但当前对照不能把 RNA 主效应与 RNA–Patch 检索贡献分开。**

本文件前四节的原始组件审计只核查已存在的检查点、特征缓存与 OOF，并计算 CPU 线性读出；该工具的新增训练与 Patch/神经网络前向均为 **0**。随后补充了尚未进行过的15模型冻结q-only/Value-only GPU归因，见 `C4_ROUTING_ATTRIBUTION.md/JSON`，因此不应把整个Phase25-A称为0次GPU推理。逐PC补充也只做CPU线性读出，没有重新训练。描述性排序记账读取旧 OOF 的受保护 DSS 终点，患者数组、基因列表与权重均未公开。原始组件工具为 `scripts/audit_phase25_a_visual.py`；对应匿名统计为 `VISUAL_ATTRIBUTION.json`。

所有指标沿用 within-fold 配对，先汇总每个 seed 的五折分子/分母，再对三个 seed 求均值。不跨折比较风险、不平均风险后算 C-index。本次没有注册新的确认性区间；冻结分支去除不能解释为重新训练后的必要性或因果归因。

## 3. CONCH 直接读出与 CS 重优化的冻结分解

将已拟合模型写为 `r_full = X_CS w_CS,joint + X_CONCH w_CONCH`。保持同一组联合权重，单独读取前一项；再与独立 CS Cox 比较。这不重新拟合任何模型。

|冻结读取|Harrell|Uno60|
|---|---:|---:|
|独立 CS 正式参照|0.814161|0.783318|
|联合模型里的 CS 项单独读取|0.815338|0.777309|
|联合模型完整风险|0.825923|0.806707|

因此，CONCH 项在该冻结联合模型中的净配对信用变化为 **+0.010586 / +0.029397**；CS 联合系数漂移单独为 **+0.001176 / −0.006008**。这些是风险函数的记账关系，不能据此估计重训后去掉 CONCH 的效应。

以 Harrell 可比患者对信用质量记账，先各 seed 汇总五折，再三个 seed 平均：

|比较|修复质量|损伤质量|净变化|
|---|---:|---:|---:|
|完整 LOCAL−独立 CS（已有结果，本次精确复现）|0.030581|0.018819|+0.011762|
|完整 LOCAL−冻结联合 CS 项|0.030816|0.020231|+0.010586|

|LOCAL−GLOBAL_MATCHED（已有结果）|0.004470|0.003764|+0.000706|

Uno60 完整 LOCAL−冻结联合 CS 项的修复/损伤加权质量为 **0.044168 / 0.014771**。质量包含 tie 的半信用，不应称为新增患者人数；不同基准下的修复/损伤质量也不能直接相加。

15单元等权的 heldout 风险分量 SD 均值：联合 CS 项 **0.37405**、CONCH 项 **0.09509**、CS 重优化变化 **0.01419**。历史表列名 `clinical_component_sd` 实际包含 **Clinical+S32**，不能解释成单独 Clinical。

## 4. C4 的 anchor 优化与 deep residual

C4 保存了 Ridge 初始化后的 `initial_state` 与训练后的 `state`，因此可读取同一患者特征上的初始/最终 anchor。旧源码的实际风险是：

`risk = joint_trainable_Clinical_S32_anchor + 0.1 * deep_head`

该 anchor **不是冻结风险**。本次用原始 float32 Clinical/S32 与对应 checkpoint 线性权重在 CPU 计算：

|读取|Harrell|Uno60|
|---|---:|---:|
|C4 初始 Ridge anchor|0.805928|0.773719|
|C4 共同训练后的 anchor 单独读取|0.795578|0.749017|
|原始完整 C4|0.813691|0.802965|

冻结共同训练权重后，deep residual 在最终 anchor 上增加 **+0.018113 / +0.053947**；最终 anchor 相对初始 anchor 单独变化为 **−0.010351 / −0.024701**。完整 C4 相对初始 anchor 为 **+0.007763 / +0.029246**。这说明不能把 C4 的全部点估计收益归因于 Clinical+S32 线性系数优化；也不能把共同训练中分支相互补偿解释为 anchor 参数更新必然有害。

Harrell 的修复/损伤信用质量：deep residual 相对最终 anchor 为 **0.077394 / 0.059280**；anchor 变化相对初始 anchor 为 **0.010743 / 0.021093**。15单元等权 SD 均值：初始 anchor **0.73880**、最终 anchor **0.89201**、anchor 漂移 **0.17392**、全部 deep residual **0.57042**。

## 5. RNA 主效应与检索仍缺什么

**已有：**

- Phase12 在128 Patch 下 Real 相对 Null/Wrong 双指标三个 seed 点差均正，但原始和校正区间均含零；512 Patch 并未复制 Real−Wrong 的双指标正向性。
- 原15个固定 C4 采用训练均值 RNA 和20次锁定 split 内错误患者 RNA，三个 seed 的匹配风险排序均高于错配上下文均值；它验证模型对 RNA 身份有响应，不是20个独立实验。
- NoAnchor Real/Null 真实重训已完成，但改变了读出路径与优化条件，且 RNA 增量方向分裂；它不能单独隔离检索机制。
- RNA-only 富集集合有可解码排序信号，不等于 C4 中检索优于相同表示的加性主效应。

**新增的独立查询/检索审计：**

- 保留本人RNA Query残差，只将attention q换为fit RT逐槽均值或错患者RT，得到 **0.810162/0.784256** 和 **0.806477/0.777534**；相对原C4两指标总体点估计下降。全部15原模型风险精确重放，权重未变。它将检索q作用与本人Query残差分开，证据比RNA全路径错配更具体。
- 只删除RNA→Patch的Value消息、保留本人Query残差及原FF，得到 **0.819572/0.795359**；Harrell提高、Uno60下降，不能认定该局部分支具有双指标一致必要性。详见新增 `C4_ROUTING_ATTRIBUTION.md/JSON`，没有新增确认性区间。

**仍未被识别：**

- C4 的 RNA→Patch CrossAttention 为 `query + attention_value`，再进入残差前馈；保留患者 RNA Query 残差。因此 Real/Null/Wrong 同时影响 RNA 主效应和条件检索，不能只归因于检索。
- 当前仍没有同一 C4 RNA 表示、相同主效应和预算下的纯加性风险真实重训对照。新增冻结路由审计并不填补这一重训比较，也不能把所有 deep residual 称作 RNA 或纯跨模态交互。
- 现有分解不能证明语义 ROI、空间形态对应或医学因果关系；没有原图组织学核验。

新增研究应以这些实际缺口为范围，避免把已经完成的 λ、GLOBAL_MATCHED、Null/Wrong、NoAnchor 消融再做一遍。

## 优势、风险与置信度

**优势：** 使用真实仍在的检查点及字节回执；不训练、不生成外折错误监督；线性风险精确重放；将既有主要区间与新描述性冻结记账分开。

**风险：** 512患者/65 DSS事件同队列反复研究；本次没有新增确认性区间；固定风险配对不含重训或内层选择方差；C4 初始/最终 anchor 的计算读取为 CPU float32，并未重复 GPU 全网络回放；不同历史模型并非同一输入/训练协议。

**置信度：高**——文件覆盖、字节一致性、已有控制的存在及本次线性记账；**未确立**——局部选区独特泛化优势、纯 RNA–Patch 检索收益或医学语义因果解释。
