# 查询表征与机制审计

本审计仅探测各内层训练分区按既定顺序的前32名患者，未按事件、风险或模型得分挑选患者，不读取外折测试患者做探测；所有患者级风险仅在内存中用于汇总。

**保留 RNA512 主效应旁路，只能证明存在直接信息通路，不能证明 RNA→Query 编码无损。** 逐 Token LayerNorm 可能削弱幅度信息；RNA 数值乘1.1、基因身份置零和正确/错误患者替换分别探测数值敏感性、身份依赖与患者条件变化，不能单凭这些统计量宣称预后排序保真。

**A7 的范数匹配在门控之前、使用其自身参数检查。** 后续 Gate 可改变范数；不同模型独立学习后的消息范数也不要求逐元素相等。四路径参考退化、零行和以及非零消息只能验证算子属性；是否有预测收益应由独立锁定的比较回答。

PCA 审计从实际私有选区位置重建训练样本，重新拟合 PCA64 与 LOCAL PCA32，核查训练患者归属、每患者采样上限、组件、参考值和实际缓存特征哈希。CSV 与 JSON 仅发布匿名聚合，不包含患者标识、所选基因列表或风险数组。
