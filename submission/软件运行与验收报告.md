# 多模态肿瘤生存风险预测与分析软件 V1.0
## V1.0 实际运行与验收报告

### 验收日期与条件
报告制作日期：2026-11-07；本地容器环境；Python 3.13，NumPy 2.3.5、SciPy 1.17.0、scikit-learn 1.8.0。训练演示仅使用虚构患者，未使用任何TCGA数据、医院信息或第三方基础模型权重。

### 执行的实际命令
```bash
python -m r4surv demo --out examples/synthetic_demo
PYTHONPATH=. pytest -q tests/test_release.py
python -m r4surv predict --input examples/synthetic_demo/synthetic_features.npz --model examples/synthetic_demo/r4_model.json --output examples/synthetic_demo/standalone_prediction.csv
python -m r4surv train --input examples/synthetic_demo/synthetic_features.npz --output examples/synthetic_demo/standalone_model.json
```
