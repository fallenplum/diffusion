# 多模态肿瘤生存风险预测与分析软件 V1.0
## 技术设计说明书（内部技术文档）

### 1. 系统总体架构
系统是离线Python研究软件，采用输入接口、预处理、统计生存模型、冻结模型存储和输出导出五层。第三方病理基础模型在系统之外完成WSI编码；本软件使用患者级病理特征。软件不访问病历系统、不与医院网络连接。

处理流：患者级NPZ→字段校验→Clinical编码→S32标准化→CONCH Local PCA32→RNA512训练折内筛选→CP/RNA独立Cox→teacher交叉拟合标量校准→JSON模型→新数据风险预测→CSV。

### 2. 模块目录
- `io.py`：无Pickle NPZ输入的形状检查与有效值检查。
- `preprocess.py`：临床类别编码、S32标准化、CONCH PCA32及RNA筛选。
- `reference.py`：Efron风险集、可比较患者对、IPCW Uno60评估。
- `cox.py`：L-BFGS-B优化的Efron-Ridge Cox与teacher标量校准。
- `model.py`：三teacher交叉拟合、全训练重新拟合、JSON状态序列化。
- `demo.py`：完全合成、固定随机种子的演示特征生成。
- `cli.py`：命令行入口、CSV和JSON报告生成。
- `tests/test_release.py`：计算、输入和端到端验证测试。

### 3. 模态与基础模型的准确关系
`conch_local`是已在仓库内完成的预提取CONCH局部Patch聚合向量，每患者768维；软件不会重算原H5，也不要求具备SVS文件。
`S32`来自TITAN视觉语义投影与32条预定义结直肠癌形态文本原型的余弦相似度；不等于TITAN原生768维，也不是32项确诊病理标签。两模态特征不直接共享空间token，而是在正则Cox层合并。

### 4. 数学计算配方
给定标准化临床向量C、S32语义向量S、局部病理向量P，以及高维RNA X。训练折先拟合均值方差与PCA32：`CP = [scale(C), scale(S), scale(PCA32(scale(P)))]`。
RNA列由训练数据中非缺失率不低于0.9、方差大于1e-16及固定标注集合优先规则，得到512列。先按训练折统计标准化，缺失位置仅归零，再次训练折标准化所选512列。
各分支使用`L_Efron(w) + λ/2·||w||²`。强CP λ=10；RNA λ=1，数值优化采用SciPy L-BFGS-B，不构造512×512 Hessian。

在3个训练折teacher中，每个患者在自身未参与拟合的teacher上获得标准化CP与RNA风险`r_cp_cf`和`r_rna_cf`。对于来自同一teacher分区的可比较患者对(i,j)，用`log(1+exp(-(Δr_cp+βΔr_rna)))+β²/2`最小化得到β。该步骤禁止以同患者样本内监督风险直接学习β。

最终在全部训练患者上单独拟合两条Cox，并按其各自训练风险的均值/标准差归一，输出`r = r_cp + β·r_rna`。本版仅给出相对分数，不报告基线风险、绝对生存率或生存曲线。

### 5. 质量与稳定性控制
- 无结局特征处理仅在对应训练患者拟合，预测时不重新拟合。
- Efron并列事件显式展开风险集，不混用Breslow损失。
- 标量校准只用同teacher的可比较患者对。
- 严格输出非有限数值检查；任何拟合梯度超标时拒绝输出成功。
- `patient_id`行必须唯一；缺失的分类取训练集合之外的全零编码。
- 模型以UTF-8 JSON保存，避免不可信Pickle任意对象加载。
- SHA256校验输出用于确认交付文件未变化。

### 6. 运行与测试
环境：Python≥3.10，NumPy/SciPy/scikit-learn；不需要GPU。完整合成运行`python -m r4surv demo --out demo_output`。自动测试`python -m pytest -q tests/test_release.py`。输出`demo_receipt.json`带合成患者数、事件数、分割统计、模型β、合成测试Harrell及Uno60和三份文件的SHA256。

### 7. 输入输出数据字典
输入NPZ键名与格式见《使用说明书》第5节。输出CSV包括患者标识、融合相对风险、病理临床风险与RNA风险。输出JSON为冻结的预处理参数、PCA参数、模型权重、风险尺度、融合β与审计信息，不包含原始患者输入矩阵。

### 8. 开发来源与复现边界
本软件为原`fallenplum/diffusion`的BG-BEN R4 CP_SCALAR计算路线重新整理的独立发行版。核心参考实现位于`src/bgb_en/protocol.py`、`src/bgb_en/baselines.py`、`src/bgb_en/survival.py`、`src/phase10_trimodal/math.py`及`reference.py`，来源分支`research/qpr-fusion-v1`。为了离线发布和验证，软件移除了与真实TCGA资产、CNA审计接口以及研究实验记录强耦合的部分。训练流程和数值接口应当视为**功能等价方向的再实现**，而非已完成真实R4逐患者、逐参数的数值等价验收。

### 9. 第三方组件和知识产权
外部依赖NumPy、SciPy及scikit-learn；CONCH、TITAN只作为上游特征来源。未捆绑其源代码、权重或论文图表。软件算法思想、模型配方与原创源码表达是不同的权利对象。校内项目贡献者与著作权归属、可能的合作开发协议及学校规章必须提交前确认。

### 10. 测试结果适用范围
本发行版使用合成输入测试流程与数值运算，不具备外部医学评价价值，不提供临床性能保证。历史在TCGA512名患者上的DSS C-index不能直接填入本发行版的性能说明；待合法取得原数据、原特征及预处理状态后，方能在锁定协议下另行开展真实数据比对。
