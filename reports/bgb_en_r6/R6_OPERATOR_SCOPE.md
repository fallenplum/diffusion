# R6 算子与结论适用范围

本说明依据已经锁定的实际代码，在查看完整目标性能门槛前记录。它不改变模型、训练预算或选择规则。**代码事实的可信度高；它们是否解释最终表现，仍须结合实际诊断，不能先当成已证实原因。**

下文末尾另列完成后只读复核发现的实现覆盖边界；该部分属于结果后审阅，不冒充事前假设。

## 1. 本版本是串联的双差分反馈

当前前向修正为 `ΔE = Read(q_cond, P) − Read(q_base, P)`，反向修正为 `ΔG = GeneRead(E_cond, RNA) − GeneRead(E_base, RNA)`。

因此若 `E_cond = E_base`，反向差分也精确为零。该设计隔离“RNA 改变病理读取后，再改变原基因读取”的反馈增量；它没有单独检验不依赖前向修正的 Pathology→Gene 路径。后级可能承受上游差分幅度的限制，这是算子性质，不能仅凭 B7 阴性否定全部双向交互。

B6−B5检验同源、无新增显式先验时，真实基因读取相对压缩 Token 读取的效果；B7−B5还改变源先验，须分开解释。

另一个明确边界是：两个方向的风险头均先对四个程序修正取均值，再使用共享线性头。它不是完整保留四个位置的程序特异读出；例如两个程序的修正恰为相反向量时，均值会将其抵消。当前未用新的真实重训隔离这一读出约束，不能据此宣称它就是表现原因，也不能把阴性结果推广到全部保留多Query信息的架构。

## 2. 源对齐与目标条件化的尺度合同不同

S7 的对齐损失对视觉与分子向量使用 L2 单位化，比较角度；目标 Query adapter 使用未单位化的 `G0`。对齐项本身对非零向量的正比例缩放不敏感，但完整源损失还含参数 L2，因此不能说整个源模型完全没有尺度约束。

这只是一个必须核查的接口尺度问题。附录将记录 G0、Query、ΔQuery、Ebase、ΔE、反向基因读取及 ΔG 的实际范数；不据其事后调整输入尺度或挑选最优缩放。

源S7的四个视觉程序表示为同一视觉状态加各自Query后单位化，程序名称不同不自动保证四个表示独立。不同程序的实际可分性由检索重叠、相关与注意力有效秩描述，不能单凭模块名称成立。

## 3. null 权重不是医学置信度

病理读取包含零 value 的 null 候选。若真实候选分数与 null 分数均为零，N个候选时 null 权重为 `1/(N+1)`；N=128 时约0.00775。因此该数值同时依赖候选数量与分数尺度，不能直接解释为经过校准的“无对应证据概率”。

原基因读取在实测有效成员内归一，成员全部缺失时输出无效/零；这与另设一个经过验证的分子来源 unknown 分类器是不同功能。

## 4. 本目标模型并非只训练一个线性风险头

所有基础来源参数冻结，强 CP＋RNA512 风险保持固定；但目标模型还训练共同的 Hallmark 主效应辅助编码。其可训练参数为29,988，B7总可训练参数为35,652。不能把本轮描述成“仅训练薄风险头”。

各臂保留相同辅助分支预算，有利于方法比较；它仍可能影响小事件数下的共同优化。风险附录将区分主效应与交互幅度、纯Cox路径梯度及参数漂移，不用总梯度大小代替交互有效性。首8训练患者的Cox微批贡献与全参数L2梯度作用范围不同，二者不能相减得到因果归因。

## 5. 输入支持和终点边界

四程序注册760个基因，TCGA RNA精确匹配681个，支持集与原RNA512不同。保真差异同时涉及基因支持、测量覆盖、非线性映射与L2几何；不能全归因于维度或生物先验。

本阶段源任务验证局部图像—实测程序的预测对应，目标任务检验强主效应之外的DSS排序增量，两者不相互替代。六个来源供体已被开发复用；其与TCGA的患者级互斥仍未通过共同登记证实。既有外折不是新的独立验证。

## 优势与风险

优势是明确保留本人测量、主效应、真实重训控制和实际回放，能够定位一个具体实现在哪条计算路径上起作用。

风险是串联差分、未直接匹配的潜在尺度、辅助主效应容量及有限来源/事件数共同限制结论。负结果应限定为当前冻结输入、固定算子与训练协议，不升级为所有医学对应或所有原基因交互均无价值。


## 完成后的实现覆盖复核

本次交付完成的是锁定配置和源码所定义的 R6 矩阵，不代表原工作单提出的每个可选候选与可学习状态算子都已验证。

- 原工作单描述了门控的程序状态更新 `G_prime=G+gate*U(R,E)`。当前目标实现计算 `GeneRead(E_cond,RNA)-GeneRead(E_base,RNA)`，将差分交给共享风险头，没有将一个独立的门控 `G_prime` 再送回下一轮局部交互。在相同 reverse mask 下，定义虚拟状态 `G_prime=G0+deltaG`，当前线性增量等价于同一交互读出 `rho(G_prime)-rho(G0)`；因此原基因重读确实参与前向风险。这是固定 gate=1、恒等增量映射的简化残差特例，未实现可学习 gate/U，也未将更新后的状态用于下一轮查询。不能将其说成原基因路径完全缺失。
- 目标 `base_queries` 重新随机初始化；源 ST 查询主要通过冻结的源分数先验进入 B7，并非直接复制成目标基础 Query。B6、B7都使用同一 S7 来源，区别包含新增的显式源先验。
- 源 S7 是真实 spot 图像—表达配对监督，`use_spatial=False`；它没有同时继承 S6 的邻域适配损失。S6、S7分别检验，不应写成已经完成“空间邻域图＋配对监督”的统一源模型。
- 四个 ST 程序各以一个 signed 64D 状态进入主要交互；正、负成员通道的中间值和 mask 在编码中处理，但没有作为多个独立子 Token 保留。Hallmark 多子模式只属于共同单模态主效应分支，不能用它冒充四 ST 程序的多子 Token 交互。

这些缩减限制了对原完整构想的检验范围。它们没有改变保存模型的数值回放事实，也不授权在已见内层结果后不设边界地增加拟合。本轮阴性结论仅针对已锁实现；若要验证未覆盖的门控状态更新、直接源 Query 迁移或多子 Token，须另立一个单独锁定的实验，而不是将其声称为本轮已经检验失败。
