# SPGEL：当前开发 pilot 的决策

**图像到四程序预测出现一致的开发增益；尚未证明双向重读带来稳定的精细空间对应，也尚未完成官方基准或独立来源确认。** 本结论只使用固定源任务，不使用 R8、DSS 或 PFI 的成绩选择模型。

## 1. 实际完成范围

固定六供体、十二切片、13,011 spots；72 个 LODO 拟合含 12 个真实凸拟合和 60 个神经拟合。全部 192 个状态实际重载回放通过；另完成两个预锁全源拟合及六次状态回放。合计 **74 次拟合、54,080 次神经更新、198 次实际状态回放**。A1 与 A5 同时导出，不按下游结果选择其一。

主结果来自 epoch40 的未参与训练供体。epoch10/20 只作训练诊断，不用于选 checkpoint；全源 S4 的训练指标不进入 LODO 主表。[逐供体表](S3_PER_DONOR.csv)、[完整结果](S3_PILOT_SUMMARY.json)。

## 2. TASK-A：存在有价值的源预测信号

每个供体先对四个程序计算严格宏 Pearson，再对六供体等权平均。以下是两次真实随机初始化的结果；供体仍是同一组历史开发对象。

| 模型 | seed31 | seed47 |
|---|---:|---:|
| 图像预测组织主效应 A0 | 0.036488 | 0.036488 |
| 容量匹配图像 MLP A1 | 0.333787 | 0.368670 |
| 空间 GraphSAGE A2 | 0.374069 | 0.384224 |
| 单一对比对齐 A3 | 0.392956 | 0.365900 |
| 程序位置与组织主效应/残差包 A4 | 0.414770 | 0.392768 |
| 双向原始证据重读 A5 | **0.428016** | **0.421925** |

A5−A1 为 +0.094229、+0.053255，两次初始化均六个供体方向全部为正。A5 与 A1 参数数分别为 333,203 与 333,331，因此该比较具有近似容量匹配支持。它支持继续验证源程序表征，**不证明细胞来源归因或生存增益**。

A5−A4 为 +0.013246、+0.029157；逐供体正向数分别 3/6、5/6。A5 比 A4 多 32,768 个参数，当前不能将全部差异单独归因于双向读取机制。A4 相对 A3 还同时改变了程序位置、组织分解和组织监督，是预定模块包比较，不是逐项因果消融。

## 3. TASK-B/C 的限制不能掩盖

TASK-B 允许使用真实配对 ST，与纯图像预测信息预算不同。A5 的 native image→gene / gene→image pair AUC 分别为 0.605761 / 0.585554（seed31）和 0.618397 / 0.601293（seed47）；Recall@1 约为 0.000651–0.003906。A5 并未在两次初始化、两个方向上稳定超过 A4。没有完成匹配组织/测量深度的错误对应真实源重训，因此**精细患者/spot 对应机制未确认**。

TASK-C 固定使用训练供体程序的第 90 百分位阈值。每个留出供体至少有一个程序没有高活性阳性，因此严格四程序宏 AUPRC 在 **0/6 供体可定义**，两种初始化均为 null。例：iCMS2 在两个供体没有阳性；iCMS3 在四个供体没有阳性。各可定义程序的 AUPRC、Pearson/Spearman 和支持数仍保留在完整 JSON，不能把 null 填成 0，也不能改用测试供体分位数制造可比较主分数。

这一结果首先暴露了固定高活性终点的跨供体支持限制，并不等价于图像完全不能预测程序。空间图是实测 ST 程序代理与 held-out 图像预测的比较，不是病灶分割、单细胞来源或因果调控真值。

## 4. 当前决策与下一步

**优势：** 同一固定供体级源分折、近似容量匹配的 A1 对照、完整状态回放、没有测试 RNA/真实组织标签进入 TASK-A/C、保留全部供体与空指标。

**风险：** 只有六个历史开发供体；A5−A4 仍有参数差异和供体异质性；精细检索增益不稳定；高活性终点支持不足；ST 与 TCGA 的测量和物理支持不同。

对上述完成计数和开发集数值的置信度高，依据是实际保存状态回放及独立 1,316 项聚合算术核查；对新来源推广、细胞来源解释和三模态生存收益的证据仍不足。

下一步先完成官方 HEST 50-HVG 及独立来源的身份/配准/单位资格与强基线。当前 E 盘未挂载，新增原始数据按用户要求等待写入 E 盘，不改到其他盘。没有新增原图或独立测试，不声称 SOTA、独立确认或整个 S0–S4 研究已全部完成。

当前 R8 保持旧 `R6_S7_locked`。新导出 A1/A5 权重不得静默替换旧结果；真正验证新源表示的 DSS 转移，需要另行资格和明确版本 `R8_SOURCE_SPGEL_V1`。
