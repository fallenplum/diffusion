# 文本路由与输入公平性边界

B3 保守对照只随机旋转固定 Query 的语义方向，保留真实 S32；它不是完整无文本模型。TEXTLESS 以独立随机视觉读取器和 native 视觉投影替换显式文本原型、概念 cosine 与得分分支，同一容量投影真实参与前向和梯度。score-route 对照只匹配当前训练分区的得分一、二阶统计，不声称匹配完整条件分布。

两通道分别在 measured 支持内归一化已知与未知边，缺少已知支持时安全回退；未知不等于错误。原先验只有 15 条来源候选，聚组后已知关系只覆盖 6/50 个分子程序。两通道移除了原先不再执行的一个未知强度参数，B3/B4 同步变化，不用无用参数补预算。

T2 的三种冻结 Ridge 都保留相同 clinical64。mean64 对照为 128 维，保留槽位及二阶容量控制均为 576 维；名义系数分别为 6,450 和 28,850，不能将名义系数数等同于有效自由度。交叉验证只重新拟合头；编码器曾使用全部当前训练患者，因此它不是完整流水线的 OOF 预测。

P2 必须统一保留强锚点 r0，而 r0 自身包含 S32。因此 P2 的 TEXTLESS 只能严格解释为“增量编码分支没有显式文本”；完整风险仍包含共同锚点的文本信息。相关比较检验给定同一含语义强锚点后的额外文本路径，不能宣称整个预测完全无文本。这项合同边界在外折评分前公开。
