# R6 独立综合说明：源对应可预测，但当前 TCGA 交互配方未形成有效预后增量

日期：2026-10-28。本文是既有实验的综合审阅，不改变科学源码、训练配置、报告器、选择规则或训练预算，也不启动新训练。

**核心判断：当前 R6 配方没有通过预锁的 DSS 机制门槛。证据直接指向目标条件交互分支在该实现中的有效风险贡献近乎消失；它不支持否定医学对应关系这一研究思想，也不足以认定“65 个 DSS 事件”是唯一原因。**

## 3. 目标结果：未检出当前交互机制的有效贡献

### 3.1 预锁主终点没有形成双指标优势

完整目标结果中，B1 的 DSS Harrell/Uno60 为 0.825898953/0.787859363，B7 为 0.825140343/0.791305883：

| 直接比较 | DSS ΔHarrell | DSS ΔUno60 | 解释 |
|---|---:|---:|---|
| B7 − B1（强 CP＋RNA scalar 参考） | −0.000758610 | +0.003446520 | 一负一正，未通过双指标均优门槛 |

PFI 的 B7−B1 为 Harrell −0.000536830、Uno60 −0.006205483。它不能替代 DSS 的主终点判断，也不能据此在不同终点间挑选有利结论。

B3、B4、B5、B6、B7、B9、B11 得到相同的生存排序表现。这里应表述为保存风险的排序/评测未发生可检测改变，**不能未经逐元素检查把它升级为所有风险张量完全相等**。尤其是正确与错误患者 Query、关闭反向原基因重读等控制没有分离，当前数据没有支持所希望的患者特异性交互效应。

### 3.2 风险与注意力诊断互相一致

本轮已核目标诊断给出：

| 诊断 | 数值 | 能说明什么 |
|---|---:|---|
| 交互风险修正 SD / anchor SD | 1.337774996×10⁻¹² | B7 九单元完整验证风险的均值；最终交互贡献近乎消失 |
| 主效应修正 SD / anchor SD | 0.025080887 | B7 九单元完整验证风险的均值；仍可学习的输出主要来自共同主效应路径 |
| 正确/错误患者条件的注意力 TV | 2.135930117×10⁻⁷ | 九个 B7 单元中，预固定首八验证患者探针的均值 |
| 条件 Query 改变 / base Query L2 | 0.003400349 | 同一首八患者探针；不是 Query 完全没有响应 |
| 病理差分 ΔE / Ebase L2 | 2.357629587×10⁻⁷ | Query 变化没有转化为相称的读取变化 |
| 反向原基因差分 ΔG / 原读取 L2 | 1.117048786×10⁻⁸ | 串联反馈进一步微弱 |

注意力与中间范数探针使用各分区预固定的首八验证患者，共 24 个独特患者；不能把重复评估当作 72 或 720 个独立患者，也不把探针结果说成全 512 人的统计。风险 SD 比值不是预测方差解释率。

这里还要区分**程序差异**与**患者条件差异**：B7 不同程序之间的 top16 Patch Jaccard 约为 0.1946，说明程序之间存在选区区别，不能说四个程序全读同一选区；但同一程序在正确/错误患者 Query 下的 top16 Jaccard 为 1，配合约 2.13593×10⁻⁷ 的 TV，说明患者条件几乎没有改变读取。原始注意力有效秩约 1.0943 指每张 WSI 的未中心化真实 Patch 权重矩阵，**不是**整个人群的表示秩或 latent 秩。完整验证人群的九单元 cross-risk SD 均值与这 24 人探针的 TV/Jaccard/注意力秩是不同统计对象，不能混成同一全队列结论。

极小幅度本身不从数学上保证排序绝无影响；但它与多个机制臂排序相同、错误患者控制未分离共同出现，使“当前条件分支塌缩、未形成有效风险通路”的解释具有较高置信度。

这与“模型已经有效完成交互，只因 C-index 不敏感而看不出来”不同。也不能仅凭这组最终快照断言塌缩发生在哪一训练轮，或者已定位到唯一训练原因。未保存的 20/40 轮方向风险、纯路径梯度等量必须继续标为 `NOT_SAVED`，不能用最终值回填。

结果 JSON 的 `raw_reread_attribution.B7_vs_B5_also_changes_source_prior=false` 是一个容易误读的字段：其布尔值实际表示“这项带有该名称的比较是否满足一正另一非负”，**不是**“B7 与 B5 的源先验没有变化”。B7−B5 的确改变了显式源先验，因而不能单独归因于原基因重读；同源、无新增先验的严格比较是 B6−B5。

## 4. 来源监督：预锁方向通过，但迁移机制仍有边界

来源核心 gate 的两个真实重训负对照均满足方向：以下 ΔHuber 为“负对照−真实”，Δρ 为“真实−负对照”。先按供体再按 seed 等权，没有置信区间或显著性检验。

| 来源比较 | ΔHuber | Δ组织内ρ | 判断 |
|---|---:|---:|---|
| S4 对错供体 S5 | +0.063458291 | +0.160397714 | 符合来源对应的预锁方向 |
| S4 对同切片/组织/深度层内 shuffle | +0.010639955 | +0.021227555 | 符合来源对应的预锁方向 |
| S4 对加性 S3 | +0.000858235 | +0.001298920 | 增量小，不能当作普遍显著优势 |
| S4 对随机 gate | +0.000736585 | +0.001255799 | 增量小；随机 gate 仍保留置信度信息 |
| S6 真邻域对错误邻域 | −0.001481190 | −0.002746660 | 错误邻域更好，不支持本源空间适配的特异收益 |
| S7 对不含 gene alignment 的 S4 | +0.000640641 | +0.000579910 | 总体微正，seed 稳定性不足 |

S7 对 S4 的 ρ 差在 seed31 为 −0.001655176，在 seed47 为 +0.002814996。不能把总体均值微正说成两个 seed 一致。S7 相对错 spot alignment 的正向控制是另一个问题，不消除前述不稳定性。

这些结果支持的最窄结论是：**本开发来源集存在能被图像预测、并对真实配对敏感的局部分子程序结构。** 它尚未证明测得了细胞来源、肿瘤细胞内在活性，或能够转化为 TCGA DSS 的条件增量。

六个来源供体已经被开发复用；13,011 个 spot 不是 13,011 个独立患者。来源与 TCGA 的患者级互斥尚未通过共同登记证实，状态应为 `UNVERIFIED`。S6 的源域结果也不是目标 `NativeSpatialAdapter` 的完整真实重训消融，不能直接推广为所有空间监督无效。

## 5. Retention：存在可观察的信息利用损失，不能只归因于“压缩维度”

独立匿名 retention 复核确认：18 个新拟合、609 次迭代、9 个历史参考；风险回放最大误差为 0，独立目标误差约 1.78×10⁻¹⁵、独立梯度最大值约 1.01×10⁻⁷。这里的复核依据已导出的真实回放值，不冒充重新读取患者数组重算全部临床指标。

| 组学表征 | Harrell | Uno60 |
|---|---:|---:|
| 原 RNA512 Ridge | 0.720755576 | 0.707560530 |
| 原 RNA512 PCA256，保留 gene-space L2 几何 | 0.720983159 | 0.710068346 |
| ST union 原始 760 槽（实测 681 基因） | 0.576695494 | 0.650316989 |
| 冻结 S7 四程序展开 256D | 0.555530269 | 0.460757711 |
| 冻结 S7 四程序均值 64D | 0.486345016 | 0.438423699 |
| 四个 signed program 均值 | 0.535275376 | 0.437093721 |

原 RNA512 的 PCA256 对照几乎保留当前线性可解码排序，而 ST 支持集与冻结源表征明显较弱。这反对“只要从 512 压到较低维就必然丢掉排序”的过强解释。四程序展开较均值表示更好，也提示提前合并程序可能丢掉可用区别；但该结果不证明换一个读出就一定能改善多模态条件增量。

ST union 注册 760 槽，TCGA 只有 681 个精确符号匹配基因，79 槽结构性不可测；另有真实缺失条目。原 RNA512 与 union760 的基因支持并不相同，差值同时混合了支持集、覆盖、非线性映射、源/目标域和正则几何。**不能把全部损失单归因于维度、Hallmark 或医学先验。** 原 full RNA20511 历史参考的 λ=10，与本轮大部分 λ=1 也不同，不能将其描述成所有模型正则完全一致。

## 6. 与实际塌缩一致的代码限制，及尚未证明的因果原因

以下是已锁代码事实，不是事后提出的新架构结论：

1. **两个差分串联。** 前向 `ΔE = Read(q_cond,P)−Read(q_base,P)`；反向 `ΔG = GeneRead(E_cond,RNA)−GeneRead(E_base,RNA)`。前向没有改变读取时，反向差分也为零。因此当前实现没有独立检验“不依赖前向条件修正的病理→原基因路径”。上游微弱响应可能限制后级，但还没有因果重训证明它是唯一瓶颈。
2. **源对齐与目标 Query 的尺度合同不同。** S7 alignment 使用单位化向量，目标条件适配器接入未单位化 `G0`；B7 固定探针的 G0 L2 均值约 0.254415185。更精确的代码事实是：只将基因分支独立的无偏置 Value 矩阵缩放为 `αW_value`（α>0），不改变 Key、权重或 mask，signed 程序 token 就缩放为 α 倍；在远离归一化 epsilon 的范围内，归一化 alignment 不变，图像端 Huber/CE 也不读取这些 gene Value。此特定分子幅度方向没有直接的任务尺度锚点，而参数 L2 对缩小权重有偏好。**这不等于整个源损失完全尺度不变，也不证明 L2 已是实际塌缩的唯一原因。** 真实范数诊断不授权在已看内层结果后选择最优缩放。
3. **源视觉程序表征共享 z。** 源 S7 的程序向量是 `normalize(z_i+q_ik)`，四个位置共享同一视觉状态 `z_i`。同程序的实测成员与 spot 配对对齐确实存在，但没有额外跨程序负样本或独立视觉子状态，不能单靠四个程序名称保证四种不同形态。若 query 相对共同 z 很小，归一化后的差异会被压小；这是条件性的数学限制，不能未经实际范数验证就说它已发生。源小投影/四程序对齐的 prompt 未强制四套独立编码器，因此这是必须披露的表达边界，而非发现了违规实现。
4. **先 mean4，再共享线性读出。** 目标风险头先对四个程序差分取均值，再用共享线性头；不同程序的相反修正可能被抵消。该算子没有完整保留程序位置，当前阴性不能推广到所有多 Query 读出。
5. **共同 Hallmark 主效应分支占大部分目标容量。** B7 35,652 个可训练参数中，29,988 个属于共同 Hallmark 辅助编码。基础源模型冻结不等于目标只训练一个薄线性头。共同分支可能解释为什么多个交互臂得到相同排序，但参数量本身不是贡献分解。
6. **L2 是否导致条件分支塌缩尚未证实。** 当前没有只改变惩罚而保持其他路径完全一致的因果训练对照，也没有完整每轮纯 Cox/L2 梯度轨迹。首 8 患者的 Cox 梯度、全参数 L2 梯度与共享参数总梯度不能直接相减得到因果归因。

因此可以优先形成“串联差分＋尺度接口＋均值读出＋共同主效应优化共同限制了当前有效交互”的待验证解释，不能把它写成已完成因果定位。也不能由训练 80 轮和最终梯度状态断言“预算不足”或“多训必然有效”。

### 工作单与实际实现的覆盖范围

完成后的代码复核还确认：本轮主要候选是单轮串联差分风险模块。在固定相同 reverse mask 下，其反向线性风险增量等价于虚拟 `G_prime=G0+deltaG` 的 `rho(G_prime)-rho(G0)`，属于固定 gate=1、恒等增量映射的残差特例；原基因重读实际参与前向。它没有可学习 gate/U，也没有把更新后的状态送入下一轮交互。目标基础 Query 重新随机初始化，源 ST 查询通过 B7 冻结分数先验参与，而非直接复制为基础 Query。源 S7 是真实 spot 配对监督但不含 S6 邻域分支；四个 ST 程序各保留一个 signed 64D 状态，up/down 中间状态未作为多个独立交互子 Token 保留。

因此，**预锁实现矩阵的计算完成，不等于原工作单所有可选候选和可学习门控状态算子均已验证。** 当前阴性不能替代对这些尚未覆盖机制的检验。这是实现范围披露，不是新的训练、泄漏发现或检查点回放失败；本轮仍按已锁负门槛停止可选扩展。

## 7. 报告守护修复与无新训练边界

本轮对匿名结果的报告守护、聚合、谱系和诊断展示进行了只读补齐与修复：把不完整数据挡在总体结论之外；独立重建折内分子/分母、真实配对修复/损伤、预算与预锁决策；区分技术缺失、来源证据、目标风险和算子适用范围。该类改动不改变已训练科学文件、checkpoint、固定风险、epoch 或门槛，也不因报告错误重新拟合模型。

补齐 RNA 实测覆盖/平台代理、真实程序与深度相关等必要诊断时，仍只读取已有数据或匿名收据。缺失指标保留 `None`/`NOT_SAVED`，不伪造 20/40 轮量、不补造患者配对信用、不用三 seed 当独立队列，也不把置信区间或 p 值临时加进未锁协议。

发布器首次在扫描自己生成的匿名审计时，还遇到计数组键 `barcodes` 与禁止的原始行字段同名。该值是计数、没有标识符内容；修复为明确的 `_count` 组键并保留拒绝规则，新增回归验证原始标识符/数组仍被拒。此前失败的发布器、审计与执行收据保存在私有目录；未因发布故障改结果或重新训练。

**独立匿名算术 PASS 仅说明该报告版本的数字、账本与合同自洽，不等于重新进行了全部模型前向，更不等于医学机制已成立。**

七张 PNG 均已由独立审阅使用 `view_image` 做实际视觉 QA，并复核数据/PNG/SVG 绑定通过；本次综合审阅也读取了绑定文件。其内容覆盖来源 Huber、来源组织内ρ、retention Harrell、目标 Harrell/Uno60 差值、风险分支 SD 与 Query TV。QA 没有重绘、模型前向或训练。图像清晰与数值绑定成立，不会提高统计独立性或医学机制证据等级。

资源摘要在实际监测窗口内给出来源 GPU 时间加权平均利用率 96.00%、目标 88.62%，可视设备峰值显存分别为 6,663/2,473 MiB。**这些窗口包括队列等待或空闲，不是只截取训练活跃期的 train-only 利用率；采样峰值也不是逐进程精确峰值或未采样全程的上界。** 较低显存占用与较高计算利用率可以同时存在，不能仅凭显存占比判定 GPU 浪费。

来源启动时记录的 cgroup 容量合同为 62 GiB 内存、16 个等效 CPU 核；当前 cgroup 可用内存未测。宿主 `/proc` 的可用 RAM 或宿主 CPU 利用率不能代替容器实际可用资源。各任务时长之和不等于墙钟时间，本轮没有捏造跨所有阶段的全局 makespan。

## 8. 决策、优势、风险与置信度

**本轮决策：停止把当前 R6 recipe 当作已经有效的患者特异性生存交互机制；保留其真实来源对应线索与明确失败记录。** 四个问题必须分别回答：

| 问题 | 当前方向性判断 |
|---|---|
| `ST_LOCAL_EVIDENCE_SUPPORTED` | 来源预锁方向通过；限于开发来源数据 |
| `TRUE_GENE_REREAD_WORKS` | 未获支持；同源 B6−B5 与反向 B7−B11 未形成必要增量 |
| `CORRECT_QUERY_BEATS_WRONG` | 未获支持；正确/错患者 Query 未分离 |
| `DSS_BEATS_CP_SCALAR` | 未获支持；B7 对 B1 一负一正 |

Optional 后续训练没有执行；其激活门槛未满足，不将其未运行计作失败模型。文本资格仍须单独满足。外层评估明确为 `NOT_RUN`，没有新的外部验证，也没有据本轮结果追加结构搜索。

| 结论 | 置信度 | 依据与限制 |
|---|---|---|
| 正式预算及匿名指标账本完整 | 高 | 来源/目标实际回放与 retention 数值审查；本文未另做模型重放 |
| 当前目标条件交互的有效风险贡献近乎消失 | 高 | 极小交互 SD、极小条件 TV、多个真实机制臂排序一致 |
| 当前配方未通过预锁 DSS 门槛 | 高 | B7 对 B1 的 Harrell 为负，且关键机制对照未分离 |
| 源数据存在真实配对敏感的程序对应信号 | 中 | 来源预锁双负对照方向通过；仅六个开发复用供体，无新的独立来源确认 |
| 串联差分、尺度、读出或 L2 是具体因果瓶颈 | 低至中 | 算子限制和实际诊断一致，尚无逐项因果训练隔离；其中 L2 因果解释仍低 |
| 医学思想整体无价值或 65 events 是唯一瓶颈 | 不受当前证据支持 | 未完成相应的替代实现、独立外部验证或监督预算因果实验 |

优势是强主效应保留、本人基因值/mask 受控、真实重训负对照、有限预算及实际回放，使本轮可以明确定位“当前实现没有把条件交互送到风险”这一失败事实。风险在于开发来源复用、来源/目标交叉身份未证实、有限 DSS 事件、支持集变化和多个串联约束，都会限制医学与泛化解释。65 个 DSS events 是全队列量级，每个内层训练分区实际可用事件更少；这是一项限制，不是本轮已经证明的唯一因果解释。

## 拓展思考

下一阶段若另行立项，应先锁定一个可以被单独证伪的实现问题，例如“前向真实条件变化能否在保留程序位置的低容量读出下传递到风险”；不要把来源 SUPPORTED、RNA-only 排序强或某个最终 C-index 微正，分别当作三模态机制成立的替代证据。

## 你可能想知道

本轮完成了大量真实计算，结论仍然可以是“当前实现的交互通路失败，但医学对应问题尚未被否定”。两者并不矛盾。没有独立外层、未完成 source/TCGA 互斥核验时，谨慎限定结论比继续增加融合模块更符合现有证据。
