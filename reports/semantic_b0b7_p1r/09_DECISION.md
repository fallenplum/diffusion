# P1-R 科研裁决

**裁决：P1R_SEMANTIC_EVIDENCE，证据仅限共享 S32 条件下的 Query 身份对程序预测的影响。** 这不是医学概念真值、全部文本必要性或 DSS 机制已经成立的结论。

原结构在另外两个内分区真实重训后，B4−B3 的程序 Pearson 均值分别为 +0.04593、+0.05048，Huber 差值为 −0.002384、−0.002017；六个 seed×分区比较均同向。因此不能再简单描述为“真 Query 一直没有作用”。二者仍共同接收真实 S32，不能把这项对比扩大为完整无文本对照。

固定六个旧编码器、只重新拟合程序读出时，保留 8 槽的 Pearson 六次均超过 mean64；同维二阶 mean 控制没有解释全部提高。这支持编码器中存在被均值池化丢失的可解码信息。全部 18 个头的正则均选到预锁上界 100，说明本轮网格边界仍是局限；没有事后扩大网格。

**修复本身没有全面胜出。** 双通道相对原 B4 在两个复验分区的 Pearson 差分别为 −0.02620、−0.00085。真映射相对置乱映射方向反转，未证明这批候选医学关系稳定必要。真实辅助配对提高了检索 gap，但程序 Pearson 分别下降约 0.00897、0.01193；配对检索成功不能代替程序预测成功。

较低配对权重 0.03 在两个复验分区的 B4 程序 Pearson 分别提高约 0.01259、0.04120，Huber 降低约 0.001344、0.001965。分项反传也显示局部梯度竞争，但 Query 投影的两项梯度主要同向。不能将整个网络笼统归因于梯度冲突。此权重对照保留在 P1-R，不据此事后改变 P2 已指定的主合同。

进入 P2 的候选与原结构见 `10_P2_FROZEN_CANDIDATES.json`。P2 使用预先指定的双通道 a=0.5、配对权重 0.1，保留原 B4 诊断；所有匹配对照采用相同修复。选择这一主合同是继续检验既定结构假设，不是宣称它已在 P1-R 中优于原模型。DSS 预训练、教师、背景与风险头须在各自合法训练分区重新拟合。

优势是已经拆开 Query、槽位、关系与任务竞争，并有真实配套重训和状态回放。局限是同一开发队列反复使用、没有独立局部形态真值、关系覆盖稀疏、多个任务效果不一致。程序预测的正向结果不能保证在 65 个 DSS 事件下得到条件预后增量。
