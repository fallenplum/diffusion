# S5-A 实现归因的边界

本说明依据已冻结的 `src/spgel/models.py`、`losses.py`、`training.py` 和新 S5 模型代码。它是实现事实核查，不是新的模型效果或组织学验证结果；没有读取 DSS/R8 结果来设计源模型。

## 原 A5 实际执行什么

原 A5 在 `paired_scores` 内，从同一候选配对的无条件视觉程序 token、无条件分子程序 token 产生两个条件 query，分别重读图像窗口证据与已测基因证据。正、负候选均重新计算自己的条件。两个方向基于各自的初始 token 并行读取一次，没有循环多轮状态更新、null matching 或医学来源真值。

图像分支重读已投影的 spot 邻域窗口，基因分支读取四程序760基因并集中的实际观测及 mask；这不是对整张 WSI 或完整36,601基因矩阵进行无损推理。程序名称没有通过医学文本编码器进入网络；固定 gene-symbol SHA 编码是数值身份，并不代表预训练生物学语义。

`image_only_predict` 仅接受图像与有效空间邻域。图像程序预测没有调用 RNA 或两条条件 query。因此，A5 在 TASK-A/C 的增益应解释为训练期配对辅助目标改变共享图像表征的结果，不能解释为测试时利用了测得 RNA 的双向融合。配对 TASK-B 使用图像与测得表达，信息预算独立报告。

## 新 S5 控制的确切差异

- M0 保留原 A4 的图像预测及配对算子；M2 保留原 A5。新模型的共同状态、图像预测、配对分数与注意力已用合成输入逐元素比较一致。
- M1 与 M2 使用相同的两个128×128无偏置矩阵和相同初值。M1分别以本模态 token 修改本模态 query；M2使用另一模态。M1的新增矩阵实际进入配对目标并获得梯度，没有用闲置或detach参数填预算。
- M3仅保留Gene→Image条件 query；M4仅保留Image→Gene。它们都保留原有两种anchor的对比损失，不通过删一半对比目标模拟单向条件读取。
- M5的错误训练配对由独立数据/损失合同控制。本人图像监督目标与组织标签是否保留，必须在合同中明确；不能将错误监督造成的下降全部归因于配对辅助机制。
- M6只改变模型接收的成员对应；原始观测、mask、真实目标及其程序顺序保持原合同。联合置换名称、目标、query与成员只是重命名，不能当作有效负对照。成员随机控制检验基因集结构和槽位对应，不独自证明语言语义。

M0参数300,435；M1/M2/M5/M6为333,203；M3/M4为316,819。实际有效参数、计算成本、配对覆盖与路径梯度须随正式结果记录。M2相对M1、M5需要直接配对比较；“一个通过、另一个没通过”本身不是两者差异成立的检验。

## 配对冻结干预怎样解释

诊断固定取给定分区中等间距至多128行，不按程序值、组织、深度或任何结局挑选。本人配对、滚动基因、滚动图像三个运行都属于 TASK-B；滚动替换不是同组织/同深度的困难错配训练。

在图像value固定时，只把条件图像token变化解释为Gene→Image路径响应；在基因value固定时，只把条件基因token变化解释为Image→Gene路径响应。整体配对分数的变化还包含被替换模态的主证据变化，不能独占解释为路由机制。M1可以存在自适配，但其两条跨模态上下文响应应精确为零；M3/M4对应关闭方向也应为零。

注意力变化、程序名称和分数响应均不等于医学定位真值。本阶段仍使用历史六供体开发来源，不能重新称为新的独立外部确认。
