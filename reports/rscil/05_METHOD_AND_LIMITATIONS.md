# RSCIL v0 方法与适用边界

## 固定方法

三路 64D 原始 Branch 与原 R2 的原始 Patch 均值残差路径构成共同加性主干。S1/S2/S3 使用相同的两路 rank8 Linear+LayerNorm，逐元素相乘形成 Z，再用线性风险头读取。S2 用完整训练分区的普通欧氏回归；S3 用当前训练主风险对应的 Efron 信息投影。正式比较不更换输入、宽度、损失或辅助监督。

S1S 使用 P-only 与 G-only 非线性加性头，没有跨模态乘积；rank8 为 1088 个新增参数，乘积分支为 1080 个，偏差 0.741%。这不是逐算子 FLOPs 或墙钟完全匹配，运算构成有差异；参数接近不等于两种函数族相同。共同主干本身也具有非线性自由度。

真实 profiler 的受支持前向算子计数为每患者：S0 160131、S1 162203、S2/S3 162251、S1S 162212 FLOPs，输入尺寸见 PARAMETER_COMPUTE_BUDGET.json。该计数不含不受支持的归一化/GELU、反向传播、优化器及每轮几何求解，不能当作完整计算量。

训练 90 轮，新增输出 10 轮激活、接着 50 轮新增分支训练、最后 30 轮联合更新。S0 没有新增交互分支，按同总预算优化原主效应。主效应采用初始参数近端和新增参数 L2 的独立求和正则。所有风险集均为完整当前 fit，不使用微批 Cox。

模型在训练内部独立验证分区的 30/60/90 快照中选择事件平均 Cox 最低者，再在整个开发分区重新训练；同样完整执行到 90 轮并回取锁定轮次。0/10 的原始最佳轮次保留报告，但不把它们称为已经训练的交互生成器。最终测试只在选择与重新拟合后评分。

## 合成合同

N512 包含 65 个事件、N2048 包含 260 个事件。开发/测试由独立随机数流生成，分别固定 52/13 或 208/52 个事件；每个子队列使用预定事件数的 type-II 行政删失。它避免在事件数控制时混用测试和训练生存时间，但不是对所有真实删失分布的模拟。

NULL、REDUNDANT、INTERACTION、CORRELATED_INTERACTION 的风险公式和 12 个种子均在观察结果前固定。生成器允许 P/G 与 C 相关；真值中的交互由患者 P/G 去除共享 C 后的残差乘积定义，而真实网络不直接读取这些 oracle 残差。合成中固定的 768D 病理均值输入只是 P 的非学习线性展开，不增加独立真值信息。

所有臂使用训练侧 ridge Cox 教师进行精确 warm 初始化；没有真值风险或真实系数初始化。变换、教师拟合、风险集几何均只读取当前 fit。测试 oracle 只做诊断，不用来选模型或超参数。

## 不得外推的结论

合成成功也不能直接建立医学对应或真实 DSS 增量；合成失败则按预锁规则停止 TCGA，不自动放大网络、改变正则或追加种子。N2048 的结果不能挽救 N512 的门槛失败。

信息矩阵条件数、有效梯度、参数更新、风险修正非零都属于软件或训练诊断。它们不能单独证明条件预后信息、患者配对必要性或生物学机制。

没有运行的 TCGA 内外层不会生成结果表，也不将历史成绩填入空缺位置。未来若通过门槛，必须重新核验真实训练侧输入与教师谱系；本轮预留的入口在门槛前明确拒绝执行，并非已经实现/完成的真实队列训练器。

本轮不计算置信区间、bootstrap 或 p 值，不宣称外部独立验证、临床效用或 SOTA。继续与停止均由预注册的软件资格和科学门槛分别裁决。
