# BG-BEN R0：空间输入资格

**状态：输入准备完成；本报告不包含生存模型拟合或性能结论。**

## 真实坐标尺度

519 张 CONCH 原始 H5 的全坐标均具有 1024 level-0 pixel 的网格步长；520 张 UNI2-h 原始 H5 均为 512。步长由每张切片两个坐标轴上全部正坐标差的最大公约数推断，在 Patch 选择前确定，未使用 Patch size 代替 hop。

两个编码器具有不同原始网格，不按 H5 行号配对。多切片患者先在切片内处理，再按患者等权汇聚。

## 为什么主空间输入采用连续区域

|无标签几何诊断|GRID512|REGIONS512|
|---|---:|---:|
|实际选择 Patch 数|257,480|257,480|
|真实四邻无向边|115,781|421,400|
|至少有一个合法邻居的 Patch|92,753|257,385|
|有邻居的 Patch 比例|0.360234|0.999631|
|完全没有邻边的切片|262/519|0/519|
|四方向合法 scan transition|231,562|842,800|
|切片最大连通区域大小的中位数|1|64|

GRID512 的空间覆盖选择使许多 Patch 互不相邻，不能据此充分检验连续空间扫描。该发现来自坐标，不使用 RNA、临床、DSS 或模型性能。因此，在正式拟合之前固定 P1–P6 共同使用 REGIONS512，将 GRID/RAND/DIVERSE 保留为真实选区对照。

REGIONS 的第一中心为距离切片坐标质心最近的真实 Patch；后续中心按距此前中心的最小距离最大化选择。每个中心仅沿原始四邻网格执行 BFS，窗口最多 64 个真实 Patch，直到达到患者分配到该切片的预算。最终按真实 XY 排序，并保存窗口编号。Mamba/SSM 必须在窗口、切片和实际行列空洞边界重置状态，不得跨空洞连接。

该规则改善可计算的空间连通性，但不能证明窗口具有独立医学名称或组织学意义。它也改变了采样分布，因此 P7 选区对照是必要的。

## 数据和指纹

CONCH 的 519 个原始 H5 共 4,075,428,024 字节、1,278,642 个 768 维 Patch；逐文件核验原库存 SHA256。UNI2-h 的 520 个原始 H5 共 20,545,482,072 字节、3,295,129 个 1536 维 Patch，全部读取并核验有效值和原始坐标。UNI2-h 另准备 128 个 Patch 的患者预算输入。

所有缓存采用 float32 逐 Patch L2 归一化；全量和选区均值采用 float64 切片内求均值，再按患者等权平均。新全量均值与历史 float32 先求均值的缓存可能有舍入差异。强 CP 精确复现仍使用历史已审计 LOCAL 输入；P0 全量均值对照使用此次统一生成的 full_mean，二者在结果中分别标记。

每种选择均从全量原始候选建立，不从 GRID512 内重排生成 RAND/DIVERSE。原始 H5 均只读。特征、坐标、mask、原始行号、患者归属、配额、实际步长和窗口编号留在私有缓存；公开 JSON 只提供数量、匿名几何摘要与 SHA256，不提供标识、明细坐标或路径。

完整缓存指纹见 `R0_TOPOLOGY_QUALIFICATION.json`。零模型拟合、零结局用于选区决策。
