# R1：视觉特征、空间结构与预算合同

## 原始证据

CONCH v1.5 与 UNI2-h 原 H5 全部通过有限值、非零范数、真实坐标及重复点检查。读取后逐 patch 做 L2 归一化；原 H5 不修改。两种编码器的 level-0 hop 分别为 1024、512，不能按行号视作同一 patch。数量与 SHA256 见 R0_ASSET_AUDIT 和 R0_TOPOLOGY_QUALIFICATION。

## 共同输入和空间对照

- 主矩阵 P1–P6 使用同一 REGIONS512：每患者最多 512 个 patch，多切片分配共享患者预算；每窗口最多 64 个真实四邻连通位置。
- P2 的 GraphSAGE 仅在同切片、同窗口中构造有距离约束的真实 kNN 邻边；P3/P4 的官方 Mamba 沿行列和反向连续 runs 扫描，遇空洞、窗口边界或切片边界重置。
- P5 保留相同特征，按缓存原始候选序列正反扫描，移除 XY 依赖；其序列没有预设生物学意义。
- P6 保留每窗口的坐标集合和特征集合，在真实重训时固定打乱二者对应；联合重排行不构成该负对照。
- P7_GRID、P7_RAND、P7_DIVERSE 都真实重训同一 ABMIL 编码器。P0 使用全量原始 CONCH mean，不随 patch budget 改变。
- 先各切片内读取，再患者内等权汇聚；不把不同切片连成一个空间序列。

GRID512 在无结局几何资格中有 262/519 张切片没有邻边，因此正式空间主输入在任何 DSS 拟合前改为 REGIONS512。后者 99.9631% 节点有合法邻居；该改变依据几何资格，不依据生存成绩。

## 优势与限制

优势是坐标、mask、切片、窗口和原 H5 行来源均可追溯，空间和采样因素分别设对照。风险是窗口仍只覆盖部分组织，连续空间块不自动对应肿瘤、间质或浸润前沿；没有原图组织学真值，不作医学命名。当前 SSM 仅在窗口内部的连续 runs 传播，不能据此判断全片长程空间建模无效。CONCH/UNI2 的等预算比较还同时涉及网格和视野差异，不能把全部差值归因于基础编码器。

P0 是联合 Ridge Cox；P1–P7 是冻结交叉拟合 CS offset 加可训练 Patch 风险。二者使用共同数据与预处理合同，但优化目标和正则不同；P1–P6 之间才是更直接的编码器机制对照。

本文件说明输入合同，不替代正式训练完成标记。预算敏感性与 UNI2 附加实验按独立锁和结果表报告，不将准备缓存或 forward/backward 资格计为完成拟合。
