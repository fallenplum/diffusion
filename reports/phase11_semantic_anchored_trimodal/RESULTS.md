## 十项研究问题

1. **S32实际进入所有深度网络**：Scalar MLP+固定词项ID形成32token；C/S32→Patch和Patch→C/S32共用CP分支QKV；B5/D1保留S32晚融合但移除S32内容参与attention。另有C+S32线性初值通路联合训练，非固定风险残差或in-sample stacking。模块梯度、输入扰动及全部checkpoint回放独立验收。Phase10深度主干未输入的TITAN患者级语义在本轮显式输入；仍不等价病理patch医学标注。
2. **强锚点与深度CP**：A1: 0.80593 / 0.77372；A5: 0.80146 / 0.77495；A6: 0.79291 / 0.78320。A1不是PCA32，A2: 0.78499 / 0.74814单列。A6−A1、A6−A5区间在paired表；不能只按最高点估计称胜出。A1系数与当前输入逐元素回放，独立Efron梯度验收。
3. **RNA条件增量**：A3: 0.64479 / 0.62958是RNA线性独立信号；B0−A6、B0−B6、B0−B7、B0−A7均属主要family，必须同时看双指标、校正区间及三seed方向。RNA-only可预测不能推出给定Clinical+S32+Patch后的增量。详见下表裁决。
4. **Query对象/临床引导**：B0: 0.79864 / 0.78250；B1: 0.79942 / 0.77858；B2: 0.80773 / 0.78626。三者RNA/patch/scalers/预算/80epoch selector统一；B3反向、B4双向均实际方向hook通过。没有使用外折挑选某一路成为新确认性假设。
5. **RNA表征保真**：同Top512的C0–C5保存前/后raw/processed64D及trainPCA16 probe；probe lambda由严格inner模型表征选定。见RNA_SIGNAL_PROBES.csv。低维probe不证明信息论丢失；投影/缩放/正则与联合训练改变可解码性。C0: 0.79864 / 0.78250；C1: 0.79754 / 0.77242；C2: 0.80467 / 0.79130；C5: 0.80083 / 0.77278。
6. **真实分组对照**：C3: 0.80169 / 0.78976；C4: 0.81369 / 0.80296；C3−C4为预锁描述性比較。真实Hallmark只覆盖Top512的一部分，剩余有非生物补充槽，覆盖逐折公开；随机分组保持大小/所有重叠且在train均值/SD分箱内置换。只有一个随机分组，不能证明所有医学通路先验有效或无效。

## 优势、劣势与置信度

- 优势：S32在网络中可验、同输入负对照、full-risk-set Efron、nested preprocessing/selector、共享患者paired重采样及全checkpoint复放。
- 劣势/风险：一个反复研究的队列，仅65 events；注册参数不等于有效容量；Hallmark未覆盖全部Top512；bootstrap不含重新拟合/模型选择或训练IPCW再估计；某些预算边界仍未饱和。
- 置信度：当前指标与执行正确性高；机制普适归因中；外部临床泛化低。此评级不是未经数据支持的百分比。

## 拓展思考 / 你可能想知道

S32内容查询通过计算路径验收，只证明网络能利用该输入；是否带来生存增量仍由配对负对照决定。扩大patch覆盖同时改变优化难度，不能把负结果全部归因于RNA无信号。

## 本轮具体研究结论

- **强参照仍在**：A1 Clinical+S32=0.80593/0.77372。A6语义引导Patch=0.79291/0.78320，Harrell下降而Uno提高，不能称双指标优于强锚点。RNA线性A3=0.64479/0.62958，独立排序信号没有消失。
- **RNA→Patch未建立稳定条件增量**：B0−A6双指标方向不同；B0−A7未同时改善。真实RNA相对错配B7只有方向性支持，主要同时区间均包含0，患者配对机制未达门槛。
- **临床引导RNA值得保留为待检验方向**：B2=0.80773/0.78626，相对B0双指标点估计改善，但只有Harrell在3/3 seed正向、Uno为1/3。B2−A1也未通过区间门槛，不认定已成立。
- **S32查询与GroupMSA的贡献均未被确认**：B0−B5的两项均值不为正；C1去掉RNA inter-token attention也未提升两项均值。输入路径验收通过不等于机制效果成立。
- **监督保真是可解码性线索**：C5训练后processed64D RNA probe=0.63318/0.58743，C0对应=0.57249/0.55217。C5−C1的最终三模态收益仍只有方向性，不能从probe提升跳到融合机制确认。
- **不能以赢家宣称知识先验有效**：真实分组C3=0.80169/0.78976，随机匹配C4=0.81369/0.80296。C3−C4未支持真实分组优势；真实基因集覆盖仅19–22/512，fallback占绝大多数。这只能限制本配置结论，不能否定更完整的通路表示。
- **更大patch不是已验证的解决方案**：RNA交互128/512/1024分别=0.79864/0.78250、0.80028/0.78853、0.79605/0.78485，未呈双指标单调增加，预锁预算配对区间包含0。没有max-epoch选择，不能把当前结果直接归咎于80epoch上限。
- **C4仅为点估计赢家**：两项同时高于A1且3/3 seed正向，但普通95%与54项校正区间仍含0。随机对照不是医学知识创新的证据，也不是外部验证结果。
- **执行层与科学结论分开**：420次实际fit、450正式OOF记录、独立特征重建、全checkpoint回放与重采样复核通过；初版P0模型114记录已INVALID且整轮重训。后续保存/打包P2修复保留源链、失败日志及未变哈希。
- **下一阶段建议**：保留A1为系统参照；优先进一步检验RNA读出/监督保真与给定C+S32后的剩余信号。B2仅作预注册候选；暂停盲目增加patch、attention深度或将稀疏Hallmark覆盖包装成已证实机制。本轮总体INCONCLUSIVE，不是所有三模态/医学知识idea的NO-GO。

- A6与B6这两个完全无有效RNA的配置在15个seed×fold上OOF逐元素一致。两组均按原计划实际拟合，fit计数不改成复用；B0−A6与B0−B6不是独立机制证据，原保守16项校正保持不变。
