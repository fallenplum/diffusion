# R6.3 原基因重读的真实资格

## 已验证的计算路径

状态为 `PASS_R6_TARGET_REAL_DATA_AND_SOURCE_TRANSFER`。正式目标拟合前，三份完整来源 S7 模型及实际回放均已存在。四种完整来源状态各自建立独立、按完整模型 SHA 命名的冻结病理缓存；所有基础来源参数冻结。

真实数据资格核验对十个目标臂分别执行重复前向，风险逐元素误差均为零。关闭交互时交叉修正精确为零；仅错配查询时，实测单模态主效应及固定风险保持不变。原始 value 仍由本人索引提供；正式拟合还会单独记录 value 逐元素相等的冻结诊断。

对 B7 执行两次显式反向传播，另用输入导数探针核查原始 RNA 路径：未测基因的导数精确为零，已测基因存在非零交叉风险导数。来源模型参数未接收目标梯度。**本资格阶段新增拟合及优化器更新均为零**，不把梯度检查算作正式训练成功。

## 原基因与压缩 Token 的边界

原基因重读每次前向都会重新编码本人基因测量、基因身份及 mask，在固定程序成员内计算条件权重；不是把已池化 Token 再线性变换后称为基因重读。

这里的支持集是四个固定 ST 程序的 760 个注册基因、765 条带符号成员边。TCGA RNA 精确匹配 681 个注册基因；未测列和额外缺失仍保留 mask。不能把“760 个注册基因”写成“全部测得”，也不能称为对 20,511 个 RNA 基因全部进行交叉读取。

Hallmark50 的四模式、32维辅助表示只进入单模态主效应，未被冒充为经过 ST 对齐的 50 个医学程序。原 RNA512 风险路径单独保留，教师及标量系数没有重新拟合。CNA 的独立 gain/loss 只在后续条件启动臂中允许；基础 RNA-only 矩阵不声称已完成 CNA 增量验证。

## 参数与资源

共同注册参数为 144,785，但有效可训练参数随消融而变：B2/B3 为 30,660；B4/B11 为 31,492；B5/B6/B7/B8/B9/B13 为 35,652。原基因与 Token 反向臂的 Query 投影均为 4,096 参数。完整注册数相同不代表有效容量或 FLOPs 完全相同。

资格仅使用固定首批八名训练患者，峰值分配显存为 276,741,632 字节；它不是完整风险集训练的峰值或吞吐证明。正式运行的资源窗口另行记录。

## 优势与风险

优势：冻结来源、真实测量 mask、主效应隔离及可审计梯度路径均得到实测支持。

风险：有梯度不等于交互有效，更不等于真实基因调控或细胞来源识别。TCGA 病理坐标只核验原生单位，未宣称微米；源与 bulk 的测量域不同。最终机制判断仍依赖完整重训矩阵、风险实际回放、患者错配及修复/损伤结果。
