# S5 锁定任务与解释边界

本阶段分成两个数据合同。A是历史六供体的四程序机制归因，B1是官方HEST COAD/READ的50基因共享特征基准；二者不是同一目标、处理尺度或评价人群，不能直接比较绝对Pearson来排序方法。BLEEP/TRIPLEX属于单独的原生实现资格，不以共享UNI2特征适配代替。

## S5-A：84次真实重训

M0–M6 × 6个留一供体分折 × seeds31/47，共84次神经拟合。保持原训练顺序、Adam、40个minibatch epoch、batch512、本人Huber回归及组织监督；总72,800次更新，保存10/20/40三个状态并实际回放，共252个状态。40为唯一主轮次，不根据留出供体改变架构、损失、轮数或进入M7/M8。

| 臂 | 固定操作 | 实际训练参数 |
|---|---|---:|
| M0 | 原A4结构 | 300,435 |
| M1 | A4加两个同模态条件query，重新读取自身原始证据 | 333,203 |
| M2 | 原A5：两个相反模态条件query并行重读 | 333,203 |
| M3 | 只保留Gene→Image条件路径，两anchor ITC仍保留 | 316,819 |
| M4 | 只保留Image→Gene条件路径，两anchor ITC仍保留 | 316,819 |
| M5 | M2结构，只有训练ITC正配对被置换 | 333,203 |
| M6 | M2结构，只有模型gene→program成员结构置换 | 333,203 |

原A5双向重读位于训练辅助配对目标及TASK-B候选打分中；图像预测TASK-A/C不读取RNA，也不调用条件query。它是基于未条件化base tokens并行重读一次，不是多轮门控、null匹配或生存模型。M1将同等参数与算子用于自适配，是容量/重读控制；未添加闲置或detach参数。M3/M4同时少一个矩阵，不能仅凭其下降独占证明方向因果。

M5映射仅由当前训练侧的真实粗组织类别和log-library四分位分层构造，最小化log-depth差异，排除本人及同切片300µm以内的近邻。两个可能来源均被公共负候选规则排除，所有臂共享anchor支持和负候选；主回归真值与组织标签始终属于原图。映射允许跨训练供体，因此其效应不能完全排除供体/来源匹配的解释，也不能直接等同医学局部对应。源组织类别是tumor/stroma/mixed粗标注，不是测得的细胞比例。

M6固定真实目标列、输出身份、原始gene值和geneID；只在模型成员矩阵上使用训练侧测量覆盖、表达均值/SD分层的共同列双射。正负边数和所有程序交叠精确保留；不是同时重命名全部变量。原gene identity为固定symbol哈希向量，不是医学文本编码器；该负控检验成员/对应结构，不检验语言模型语义。

主比较预定为M2−M1和M2−M5。严格四程序宏平均先按供体计算，再对六供体等权；两seed分列。2000次bootstrap抽样单位是六供体，并共同保留其两seed，不能当作12名独立患者或13,011名患者。native配对检索两方向分别报告；缺乏高活性支持的AUPRC保持null。冻结注意力/token变化只说明依赖路径，不自动构成绩效或组织学正确性。

## S5-B1：独立的20开发＋20正式拟合

五臂为MLP、标准mean-GraphSAGE、同参数Identity控制、4个匿名学习query和SPGEL50_ADAPT。两任务×两官方fold×seed1，共20个开发模型和20个正式模型；全程只有当折训练图像、坐标及官方50基因作为训练信息。没有组织教师/组织真值、额外760个基因、历史源权重、DSS/PFI或R8结果。

共享原始UNI2-h BF16特征，非row-L2；训练侧StandardScaler/PCA256，训练使用fit_transform的U*S、验证/测试使用transform。目标按官方barcode/50基因顺序，仅float64 log1p；训练损失计算转FP32。图按同切片真实像素kNN构造，不冒称300µm物理邻域。GraphSAGE将自身项与真实非self邻居均值分开；Identity用self-only消息保持参数及初始化一致。

每个官方fold只在自己的outer-train建立内部开发划分。多切片时固定留出第一张训练切片；只有一张时使用8×8坐标块的固定规则，图不跨分区。READ内层不具备供体独立性，单切片内层也没有空间隔离buffer；这些相关性限制必须披露。Scaler/PCA只fit inner-train。

每个开发模型固定训练至1280轮，在80/160/320/640/1280保存。仅将该fold的五臂内部验证MSE等权平均，选共同epoch，平局取较小值；不跨fold平均挑预算，因为相反fold的训练数据会包含当前fold的测试患者。选定后在完整outer-train重拟合预处理、重新初始化训练全部20个正式模型，全部冻结后才统一执行直接官方测试评价。100个开发状态和20个正式状态实际回放，共120状态；回放不再训练或选轮。若选1280上限仍标记budget edge，不称已证明收敛。

SPGEL50_ADAPT保留原始证据逐候选重条件化的两方向ITC，温度及权重均0.1。每epoch使用至多512个标签无关、确定性轮换anchor，8个无自配负候选；两anchor方向分别重算，不能复用正对已条件化表示。只有训练侧gene值/ID/mask进入此辅助目标，主预测数值及梯度不依赖RNA输入。四个slot没有预定义医学名称，适配器不等于原四医学程序A5或BLEEP/TRIPLEX原生实现。

首版开发流程的配对MSE/基因自重建没有保留原ITC；在正式模型与直接测试评价均为0时因静态代码审计停止。8个完成开发单元、1个已初始化中止单元及1个初始化前中止任务独立披露，不能混入正式性能或把10进程称10完成拟合。修正前源码已归档，新版本独立目录和锁定；详情见S5B1_SUPERSEDED_PRETEST_COST.json。

## 外部验证与原生SOTA边界

六源供体已有历史使用；READ官方供体与其重叠，COAD部分供体身份未完全确认。因此这些比较不等同新的独立外部确认。官方50基因是固定benchmark合同，不能把已有四程序预测成绩代替其结果。

BLEEP与TRIPLEX的论文、当前官方源码、输入及许可状态在S5B_OFFICIAL_QUALIFICATION中单列。当前BLEEP入口缺属性/重复通道变换，TRIPLEX缺已资格的连续邻域输入等问题尚未通过原生训练资格。未运行的方法始终NOT_REPRODUCED，不制造成绩，也不把换成UNI2特征的版本称严格官方复现。
