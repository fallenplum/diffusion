# P2：预处理线程环境异常归因

**输入哈希异常由 BLAS 数值归约环境差异复现；没有发现患者集合、训练折、缺失掩码或尺度统计发生变化。** 该诊断没有读取 DSS、预测数组或已训练模型权重，没有执行神经前向、Cox、PCA 或优化器更新。

## 已执行的反例

| 新进程启动环境 | Torch CPU 线程 | 与正式输入逐字节一致 | 实际 input SHA 前缀 |
|---|---:|---|---|
| OMP/MKL/OPENBLAS 均为 2 | 2 | 是 | `c554d7f522f3421d` |
| OMP/MKL/OPENBLAS 均为 2 | 1 | 是 | `c554d7f522f3421d` |
| 未显式覆盖三项环境变量 | 1 | 否 | `43de14bf5b8cdf69` |
| OMP/MKL/OPENBLAS 均为 1 | 1 | 否 | `c645155cac34fa3d` |

当前 ambient 复现进程实际观察到 NumPy OpenBLAS 为 64 线程、SciPy OpenBLAS 为 2 线程。**原失败进程的具体线程环境未记录，不能将当前复现值倒填为历史事实。** 原失败错误位于第 172 行，早于第 173 行的模型加载及之后的全部前向、DSS 读取和拟合；四次新探针均确认其原私有与公开输出尚不存在。

四种新进程中，所有图像、临床、测量掩码、目标掩码、患者/分期/队列/缺失模式哈希，以及 9 项训练尺度统计哈希均精确相同。只有组学程序值及由 RNA 程序值构成的 target 哈希改变，RNA/CNA gain/CNA loss 三个通道均受影响。

进一步在同一个新进程内，只把 BLAS 限制从 2 改为 64，便精确重现 ambient 的输入哈希。61,350 个训练组学值中 6,928 个不同，最大绝对差为 `4.76837158203125e-7`；20,450 个 RNA 目标中 2,709 个不同，最大绝对差为 `3.5762786865234375e-7`。数值全部有限。这把异常定位到 `ProgramTransform` 的 float32 通路矩阵乘法归约，而不是 Torch 1/2 线程设置或训练患者范围。

## 恢复方式与边界

恢复既有复现说明中的启动前 `OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2` 即可精确重建正式输入。保留原审核源、原资格锁、严格哈希等式及 CPU 拟合阶段的单线程合同；无需修改已冻结的 20 项科学源、重训模型或放宽哈希规则。

优势：严格哈希门禁阻止了不同数值环境静默进入资格实验；同进程线程干预和分项哈希提供了具体反例。风险与局限：本诊断只覆盖固定的 outer1/MAIN/seed31 预处理分区，不能推导任意平台上的逐字节可复现性，也不提供任何 DSS 性能结论。

## 源码与实际执行区别

配套 JSON 完整保留四个真实新进程及一个双构造数值探针的匿名结果、实际命令形状、环境、线程池和原模板 SHA。通过 PowerShell 管道输入 SSH 的尾换行字节未另行捕获，因此明确区分本地源模板 SHA 与未记录的标准输入字节 SHA。
