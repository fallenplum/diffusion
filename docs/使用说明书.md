# 多模态肿瘤生存风险预测与分析软件 V1.0
## 用户使用说明书（软件登记文档候选）

### 1. 软件概况
本软件将已经取得授权的患者级病理学表示、临床资料和RNA表达矩阵转化为研究用相对生存风险分数。**本软件不读取原始SVS，不包含CONCH/TITAN权重，不生成病理报告，不是医疗器械或临床诊断软件。** 本次V1.0采用Python命令行界面，支持合成演示、特征级训练、冻结模型推理、CSV导出和风险排序评价。

软件全称：多模态肿瘤生存风险预测与分析软件。版本：V1.0。开发语言：Python。运行环境：Windows/Linux/macOS，Python 3.10及以上，推荐8GB内存或以上；模型训练取决于原始输入规模，演示不需要GPU。基础依赖为NumPy、SciPy、scikit-learn。

软件对象：经合法授权的科学研究人员和项目开发人员。其输出不应向患者提供治疗决定或临床诊断。

### 2. 科学与工程边界
本发行版复用 diffusion 项目R4强加性生存风险路径的计算结构。病理输入由 TITAN 图文对齐得到的32维静态概念相似度S32、CONCH局部Patch聚合得到的患者级768维Local特征组成。两个特征源均在软件外部提取；本软件仅负责读取并做训练折内处理。

与原项目区别：真实R4训练队列、RNA注释宇宙、患者划分和经审计的外部特征不包含在本次分发包中；演示采用完全合成数据，且没有历史模型权重。故演示只验证运行流程，不是对原TCGA历史风险预测的逐患者完全重放。

### 3. 安装前准备
1. 解压软件ZIP后进入包含`pyproject.toml`和`r4surv/`的目录。
2. 确认本机已安装Python 3.10或更高版本。
3. 建议运行`python -m venv .venv`创建隔离环境。Windows使用`.venv\\Scripts\\activate`，Linux/macOS使用`source .venv/bin/activate`。
4. 运行`python -m pip install -r requirements.txt`。运行`python -m r4surv --help`确认程序可启动。
5. 不需要接入网络服务器，也不需要申请数据库账号；合成演示完全在本地完成。

### 4. 软件主要功能
**F1 合成演示数据生成。** 生成具有完全虚构患者编号、32维病理语义、768维CONCH特征、544列合成RNA、6组临床变量及DSS生存结局的NPZ文件。合成数据来源于确定性伪随机过程，不包含真实TCGA数据。

**F2 研究数据输入校验。** 校验字段是否存在、患者标识是否唯一、输入是否满足二维形状、S32和CONCH是否有限值、训练结局是否有效。输入必须是无对象数组的NPZ，使用`allow_pickle=False`避免外部序列化对象执行。

**F3 联合表征预处理。** 在训练患者折内拟合临床类别编码和数值标准化、S32标准化、CONCH Local PCA32以及RNA筛选和标准化。所有拟合参数随模型保存；预测新患者时仅应用已训练的参数，不重新拟合。

**F4 生存风险训练。** 使用包含Efron并列事件处理的L2正则Cox模型，独立训练CP与RNA预测分支。交叉拟合生成同教师折外风险，使用同一教师内的可比较患者对拟合RNA融合系数，最终在全部训练患者上重新拟合两个基础分支。

**F5 风险预测。** 对结构一致的患者特征计算CP风险、RNA风险和融合风险。输出风险值不是绝对死亡概率，也不能直接解释为五年生存率。

**F6 文件导出和评估。** 推理结果保存为CSV；合成演示输出Harrell一致性指数和固定60月Uno一致性指数。这些数值仅为软件测试记录，不作为医学有效性证明。

### 5. 数据文件结构
本软件读取NPZ格式的特征文件，数组第一维均为患者数N，必须逐行对齐。实际应用前需确认上游RNA基因顺序、病理WSI与患者匹配均正确。

|字段名|形状|类型和说明|
|---|---|---|
|`patient_id`|(N,)|字符串患者标识，演示为SYNTH前缀|
|`S32`|(N,32)|TITAN视觉文本概念余弦相似度|
|`conch_local`|(N,768)|CONCH患者级Local/GRID特征|
|`rna`|(N,G)|原始或预标准化前RNA表达矩阵，列顺序固定|
|`gene_universe`|(G,)|布尔数组，指示固定注释/优先基因宇宙|
|`clinical_AGE`|(N,)|年龄字段|
|`clinical_SEX`|(N,)|性别字段|
|`clinical_AJCC_PATHOLOGIC_TUMOR_STAGE`|(N,)|病理分期|
|`clinical_PATH_T_STAGE`|(N,)|T分期|
|`clinical_PATH_N_STAGE`|(N,)|N分期|
|`clinical_PATH_M_STAGE`|(N,)|M分期|
|`t`|(N,)|训练时需提供，DSS随访月数且大于0|
|`e`|(N,)|训练时需提供，DSS事件状态0/1|

训练时最后两项必须存在。预测时不需要DSS结局，也不应把任何待预测患者的DSS信息传给模型。输入NA以NumPy NaN表示，模型使用训练集局部中位数作数值填补。

### 6. 最快的端到端演示
在项目根目录输入：

```bash
python -m r4surv demo --out demo_output
```

命令会自动完成创建合成数据、训练、导出JSON模型、重新载入模型并预测风险、导出CSV、计算合成测试指标、写入SHA256文件校验值。

演示目录输出：

```text
demo_output/
  synthetic_features.npz      # 虚构患者输入特征
  r4_model.json               # 非Pickle冻结模型参数
  synthetic_predictions.csv   # 融合相对风险输出
  demo_receipt.json           # 测试样本数、指标和哈希
```

`demo_receipt.json`中的`status`恒为`SYNTHETIC_SMOKE_TEST_ONLY`。文件中的Harrell与Uno60受随机演示样本影响，仅用于验证计算能够执行。

### 7. 在合法特征上训练模型
如已合法取得本地结构一致的特征文件，可运行：

```bash
python -m r4surv train --input authorized_cohort.npz --output my_model.json
```

训练样本需超过模型最小患者数量，并且三个teacher子折各有观察到的事件。程序将分别拟合CP与RNA模型以及RNA风险校准标量。模型以JSON形式保存，不持久化真实患者特征矩阵或者真实结局数组。

注意：该命令使用指定文件中的全部患者作为训练数据。用于科学报告时，研究者必须自行定义合法的患者级训练与测试划分，不能把训练指标描述为独立测试指标。完整研究协议仍以原diffusion项目已审计的五外折方案为准。

### 8. 对新患者数据预测
在新患者的NPZ文件包含相同的临床字段、S32和CONCH Local特征、相同RNA基因列时，执行：

```bash
python -m r4surv predict --input new_cohort.npz --model my_model.json --output risk.csv
```

导出的CSV有四列：`patient_id`、`risk_score`、`cp_risk`、`rna_risk`。其中`risk_score = cp_risk + beta*rna_risk`。各患者分数仅用于同一模型下的相对比较，不提供个人绝对生存概率。

### 9. 异常提示及排查
- 缺少字段：核对NPZ包含全部必须键名，特别是`conch_local`与`S32`。
- S32维度不是32或CONCH维度不是768：重新导出预提取病理特征，不要随意补零。
- RNA列数或顺序不匹配：固定上游RNA基因顺序，严禁直接交换模型和输入的基因列。
- 没有足够的RNA有效基因：检查训练折90%非缺失标准，必要时扩大训练数据，不能事后根据测试结果降低阈值。
- 缺少DSS事件或Cox未收敛：检查生存事件编码、样本量和数值异常；不要宣称当前数据可训练。
- 缺少`scipy`或`sklearn`：重新安装依赖，核对Python虚拟环境。

### 10. 功能验收

验收范围包括Efron并列事件风险集、输入字段校验、完整合成训练与推理、冻结状态一致性以及`risk_score`融合恒等式。通过只证明软件本身具有可运行的测试状态，不证明其可在临床中安全使用。
