# BG-BEN R0：真实资产与执行资格

**R0 资产资格核验已完成。** 本文件仅报告数据与执行资格；各阶段实际训练完成状态见 EXPERIMENT_LINEAGE.json 和 DECISION.md，不使用旧模型高分代替新共同协议的性能。

## 队列、终点和合法输入

TCGA-COAD/READ canonical 队列包含 **512 名患者、65 个 DSS events、5 个既有患者外折**。DSS 时间单位为月，Uno 截断为 60 月。PFI 来自独立审计后的端点表，510 名患者有效、129 个 events；原 canonical NPZ 中另有名为 PFS 的字段，本轮不将其当作 PFI。

患者顺序、原始队列与端点表 SHA256 均绑定到既有数据合同。输入临床字段固定为年龄、性别、AJCC 病理分期、病理 T/N/M；读取类别原值，编码、年龄填补和尺度变换在当前训练分区拟合。TITAN 原生患者表示为 768 维，冻结静态概念 S32 为 32 维。概念分数不作为独立组织学真值。

## 可读病理资产

|编码器|患者|切片|原始 Patch|特征维度|原始 H5 总字节|真实坐标 hop|
|---|---:|---:|---:|---:|---:|---:|
|CONCH v1.5|512|519|1,278,642|768|4,075,428,024|1024 level-0 pixels，519/519|
|UNI2-h|512|520|3,295,129|1536|20,545,482,072|512 level-0 pixels，520/520|

全部原 H5 可读；CONCH 逐文件原库存 SHA256 一致，UNI2-h 也完成全部原 H5 的读取与集合 hash。全部实际 feature 行检查有限值、非零范数和坐标有效性。CONCH 无重复坐标；UNI2-h loader 同样对每张原始切片拒绝重复、缺失、负坐标。UNI2-h 支持原 H5 的 singleton-leading feature 轴。

两个网格的空间尺度不同：CONCH 为 512 像素、20×输入，对应 level-0 patch size 1024；UNI2-h 为 256 像素、20×输入，对应 level-0 patch size 512。实际 hop 另由全部原始 XY 差值核验，不以 patch size 代替测量。没有按 H5 行号拼接两个编码器。

历史全量 CONCH RAM 缓存在重启后消失，原 H5 和索引仍完整。本轮从原 H5 建立独立缓存，不依赖旧挥发缓存，不改原始资产。512 患者预算生成 257,480 个有效 CONCH Patch；多切片患者共用预算，先在切片内汇聚，再对患者的切片等权汇聚。

## 空间采样资格

GRID512 中仅 36.0234% Patch 有四邻网格邻居，262/519 切片没有邻边。依据这一无标签几何诊断，在任何生存模型拟合前固定主空间输入为 REGIONS512：分散中心、原始四邻 BFS 连通窗口、每窗口最多 64 个 Patch。

REGIONS512 有 99.9631% Patch 存在合法邻居，零邻边切片为 0/519；按真实空洞和窗口边界重置后有 421,400 条无向邻边、842,800 次四方向扫描 transition。GRID/RAND/DIVERSE512 从全量原始候选单独建立，用于采样对照。UNI2-h 另有 REGIONS128，每患者预算 128，共 65,536 个有效 Patch。

选出的连通窗口不自动对应医学组织事件；没有原始 WSI 的独立组织学核验。本轮不会展示未取得的病理原图。详细资格和缓存指纹见 `R0_TOPOLOGY_QUALIFICATION.json/md`。

## RNA、CNA 和固定程序来源

|测量|实际 matrix shape|有限测量值|缺失值|完整患者|全部患者均测得的基因|
|---|---:|---:|---:|---:|---:|
|RNA|512×20,511|9,889,587|612,045|309|17,496|
|CNA|512×25,101|12,851,452|260|382|25,099|

RNA raw 表有 20,531 列，去重复/无有效 symbol 后是 20,511 个基因；CNA 相应为 25,131 列到 25,101 个基因。RNA 当前已经 log2(x+1)，不重复取对数；CNA 为 signed continuous log2 dosage，增益和缺失在训练标准化前分别处理。

RNA 的 203 个患者具有同一原表 3,024 列缺失模式，collapsed symbol 矩阵对应 3,015 个基因，缺失总数为 203×3,015。该模式只作为 missing-pattern proxy；实际测序平台身份未完成独立映射。缺失不是零表达，真实 mask 在填补前保留。CNA 130 个患者各缺 2 个基因。

RNA512 直接风险分支沿用历史固定八程序 union：977 个外部成员，其中 955 个出现在 canonical RNA。新 Hallmark50 的 union 有 4,384 个成员，RNA 可用 4,191、CNA 可用 4,252；与前述 RNA union 交集为 953。**历史八程序与新版 GMT 的同名基因集并非相同集合**，不能替换成员后仍称精确复现。RNA512 的选择仅使用训练折覆盖和方差；新通路表示使用独立冻结的 Hallmark50 来源。程序成员不在公开报告重复分发，来源 hash、覆盖计数见 `R0_GENE_SOURCES.json`。

## 外部空间监督与迁移范围

Stage B 当前合格输入是 6 个开发供体、12 个切片、13,011 个 spot 的 1536 维 UNI2 表示。组织类别为 tumor、stroma、mixed，不能解释为真实细胞组成。四个连续程序为 iCMS2、iCMS3、FAP-associated、MARCO-associated；表达程序分数不是细胞来源或生存标签。

这些开发供体已有历史使用记录。原 Phase22 ST-test 具有历史使用记录，不是未见外部确认；本轮 Stage B prepared 数据不读取它，也不读取 TCGA DSS。尚无新的独立外部供体完成确认。

外部原始 X 的 L2 norm 中位数为 14.98289，而当前 TCGA UNI2 缓存为 1。对应 TCGA 原 H5 同行的 norm 中位数为 15.00739；逐行 L2 后精确回放缓存误差为 0。原始尺度外部投影直接迁移至 L2 缓存存在测量尺度错配，不能据编码器名称相同宣称输入匹配。新外部预训练须单独锁定统一的逐行归一化；旧 Stage B 结果保留。详情见 `R0_EXTERNAL_TRANSFER_NORM_QUALIFICATION.json/md`。

## 执行与资源边界

原始两类 H5 共 24,620,910,096 字节；四套 CONCH512 加一套 UNI2-128 的 feature arrays 合计 3,674,210,304 字节，另有小型坐标、mask、归属、索引和均值文件。缓存采用只读 mmap 供训练复用；训练折拟合的统计量不跨折共用。所有原始数据已在服务器，不需重新下载大数据。

H5 审计加首套缓存准备耗时 119.93 秒；额外迁移范数审计耗时 25.89 秒。这些是数据资格用时，不能计作已完成的正式训练单元。GPU 训练资源、峰值和吞吐由本轮实际 profiler/单元日志记录，最终阶段成本报告追加；当前报告不预报最终总耗时或峰值。

正式协议在外折 1 的训练人群内部固定三分区、两个神经初始化 seed 开发；外折 1 的测试患者不参加该开发。各外折后续若进入最终评估，必须在其自身训练人群完成模型选择，不能把全局内层胜者重复当作每个外折的未偏选择。完整 Cox 风险集和对应训练分区 IPCW 由共同数值资格单元核验。Harrell/Uno 分别汇总折内分子分母；本轮不使用 bootstrap、CI 或 p-value 代替真实重训控制。

## 公开边界与后续状态

公开交付只包含 BG-BEN 新源码、配置、测试、匿名汇总和 hash manifest。患者级输入、OOF、权重、供体/spot 标识、坐标明细、服务器路径和凭据均留在私有目录。发布器采用明确文件列表及实际 canonical/ST 标识 denylist，未知文件不自动获得发布权限。

**R0 支持执行可用的机制实验，不构成任何架构已改善 DSS、通过外部验证或识别真实细胞来源的结论。** 最终训练和评估状态由各阶段完成收据及独立回放报告确定。
