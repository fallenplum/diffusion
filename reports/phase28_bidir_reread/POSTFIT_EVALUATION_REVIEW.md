本次复核仅检查当前代码、协议与合成数据，不读取真实患者结局、真实检查点或患者风险，不启动训练。冻结的训练源码、配置和主要比较均未修改。

## 必须处理的实际阻断

复核时 `decision.json` 保存的是Phase28-P0资格结果。`evaluate_stage()` 在该名称存在时拒绝覆盖，因此即使训练和回放全部成功，仍会在读取结局前停止。

处理原则已经交给主执行代理：正式评测前，将旧文件的**原始字节**保存为 `P0_DECISION.json`，记录原SHA及本次训练授权来源，核实归档相同后再移除占位名称，留给唯一正式评测写入新的 `decision.json`。原P0提交和其他报告保留。本复核未移动文件、未清除尝试标记。

同理，真实回放或正式评测如失败，须保留其 `*_STARTED_PRIVATE.json` 与失败证据，先审查失败阶段；不能通过自动删除标记反复打开内部结局。

## 已有评测实现能够回答什么

| 内容 | 当前实现 |
|---|---|
| 完成门 | 30个DONE、80轮/80步、检查点SHA、prepared与初始化SHA完全覆盖 |
| 回放门 | 独立推理重算300个风险向量、90个外部参照向量，绝对误差不超过1e-6 |
| 结局隔离 | 所有来源、资格、分区、参照、回放验证通过后，唯一endpoint callback才读取内部DSS |
| 主要比较 | C11−C00、C11−DIRECT，Harrell和Uno60分别评判，两个seed分别要求正向 |
| 聚合 | 每seed先合并三分区的within-fold分子/分母，再平均两个seed；不是独立患者OOF |
| Uno60 | IPCW由对应fit分区估计；不先平均风险或先算折平均C-index |
| 配对排序 | 同分区所有可比较患者对的credit转移，含ties；repair−damage逐seed闭合到ΔC |
| 分支解释 | 自己检查点的OFF是其已学习主效应，不能替换成M0；C00是独立重训臂 |
| 继续门 | 均值/错患者/constant-value冻结控制按既定规则判断；不自动打开外折 |
| 不确定性 | 当前是重复内部原型筛选；没有bootstrap确认区间，不宣称独立确认或生物学因果协同 |

置信度：对上述**代码行为与合成断言为高**；对真实运行是否全部通过不作预判。

## 新增的结局盲预算及风险尺度审计

入口：`scripts/audit_phase28_budget_readout.py --source <locked-source> --execute-audit`。

前置条件与正式评测一致：当前资格、30份完成回执及独立回放通过。它不运行模型前向、不拟合参数、不搜索缩放系数、不改变继续门。只输出匿名聚合 `BUDGET_READOUT_AUDIT.json`。

- 80轮固定预算的首末损失、最后10步趋势、交互和主效应RMS趋势、裁剪频率；记录数据梯度与包含L2后的总梯度，避免把休眠模块的正则梯度当成交互学习。
- 分开列出fit交叉拟合CP/RNA风险与valid完整fit风险的分布。它们来自不同患者分区，尺度差异只能作为诊断，不能解释为同一患者的配对校准误差。
- 分开统计外部offset、新单模态主效应、交互及总风险的SD/RMS和相关性，核实保存分支能够重建总风险。
- 对C11−C00、C11−DIRECT及两个方向消融，把总风险变化分解为**已学习主效应变化＋交互变化**。两者联合训练，不能把前者变化全部归因于交互算子。
- 统计冻结控制引起的风险响应与无结局的全患者对排名扰动。该排名扰动不是生存修复/损伤；真正生存repair/damage仍只来自正式评测。

历史prepared是pickle，读取风险参照时仍会反序列化其原有fit-label字节，但本脚本仅请求分区及风险参照key，不查看或使用标签key。脚本禁止np.load、optimizer构造、backward和autograd.grad，独立记录零调用。

## 优势与限制

**优势：** 预算、幅度、正则梯度与主效应漂移可以在不增加训练、不开启新结局分析的情况下审计；正式判定仍复用已经锁定的统计对象。

**风险与限制：** 固定80轮和下降的训练损失均不能证明非凸模型已充分收敛。检查点保存了风险分量，但没有每个患者逐层Patch/Gene权重、null权重或读取差分；这些量须由独立冻结前向补算，不能从风险向量倒推出。该补算也只能检验模型依赖和敏感性，不能替代独立组织学真值。
